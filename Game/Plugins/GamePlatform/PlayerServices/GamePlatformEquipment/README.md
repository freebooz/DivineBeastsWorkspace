# GamePlatformEquipment（游戏平台装备）

更新日期：2026-09-30；当前能力依据正式工作树实际文件和调用链。此前有关后端、迁移、Outbox及假支付已实现的文字被本页替代。

三个稳定模块：共享装备/拥有者公共复制快照、服务器Port/GAS授予、客户端网格挂点视觉。服务器组件在EndPlay或移除时撤销自有授予并过滤旧生命周期回调。

项目服务器组合根须注入真实已授权的装备持久化Port与GAS资产解析Port；本插件不内置HTTP持久化或长期背包权威。客户端读取公共复制快照只用于显示和挂点视觉。退出只撤销组件自有授予及回调代次，不回滚已提交的后端事务。

配置/目标/模块身份保持插件现有声明，不创建空内容包或伪造资产。

## 2026-10-09 本轮公开合同与整改

共享结构预检拒绝无角色/非正装备版本、无效物品/定义身份、重复SlotId与重复ItemInstanceId；空Slots合法，Slot.Revision允许0代表已有格式的未知条目版本，负值拒绝。公开投影仅包含槽位/装备/外观，不包含物品实例。共享复制组件、服务器授予和客户端视觉都消费预检；服务器先预检完整定义兼容，再撤销旧自有授予。无效快照不能覆盖授予/组件清理索引。

服务器组件拥有自己Grant产生的GAS句柄，EndPlay/组件销毁幂等撤销这些句柄。生命周期与持久请求代次均参与回调有效性，重复/迟到完成不再授予。现行持久化Port没有通用事务取消能力：退出失效本地消费者并释放自有Port引用，不能宣称后端事务被回滚或强制取消。生产Port仍需服务器组合根注入并校验玩家归属、库存/装备事务与幂等。

回归入口：`GamePlatform.Equipment.Server.ComponentRemoval`覆盖ASC存活、组件退出迟到完成以及重复槽位拒绝不改变旧授予/发布版本；`DefinitionAndPublicState`是结构测试。

以上Automation源码已维护，但本轮分工阶段没有执行UE构建/Automation。实际Editor、Client、Server、Cook和联机证据由根整改账本统一记录；静态源码门禁与原生CMake结果不替代这些验收。中文审核覆盖本轮修改的公开字段、命令范围、线程、异步终态、账号/资源所有权及Build责任；未据此宣称全部历史源码已完成中文审核。

### 2026-10-09 同步重入补充

服务器授权事务持有独立Port、候选快照和Definition。Resolver、GAS授予或撤销同步通知可以关闭组件；每步外部调用后复核寿命与Avatar代次，过期候选撤销全部自有句柄。撤销先脱离成员句柄集合，避免通知重入导致迭代失效。持久化Begin调用同样以局部Port和参数副本保活。

`FGamePlatformEquipmentGASGrantPort::Grant`追加默认空作用域探针参数；源码旧调用兼容，导出符号变化要求插件消费者重新编译。ComponentRemoval回归增加Resolver同步关闭组件的实际路径；本组未运行UE自动化，等待统一UE构建与测试。
