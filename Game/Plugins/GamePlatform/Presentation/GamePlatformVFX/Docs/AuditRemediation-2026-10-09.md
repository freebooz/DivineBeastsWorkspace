# 2026-10-09 表现源码整改与中文审核

本文件是本插件本次变更的伴随职责/API说明。范围只包含人工维护C++、构建规则和测试；没有创建/改写任何uasset、umap、Niagara、材质或Widget Blueprint。唯一正式实现仍在本插件Source。下面的源码检查和原生测试不能代替UE编译、Automation、Cook、设备或人工视觉验收。

所有本次服务API及回调在游戏线程运行；后台资源调度由GamePlatformData提供。值快照可复制，UObject/世界/组件指针不保证越过所属作用域。所有者关停先阻止新请求，撤销自有登记，再取消/停止实例、解绑和释放自有租约。发布通知前先完成内部所有权变更，通知处理器允许同步取消、切图、关闭服务或GC。

## 世界执行、回退、预载与终态

平台客户端世界执行器在Private；公开IGamePlatformVFXService是集成/工具接口，玩法只提交中立Presentation请求。NiagaraExecutor只执行表现，命中/护盾/传送准入仍归服务器。

Play先保留实例身份，再从Data申请空Bundle的定义元数据租约。每个World有界缓存共享元数据，但每个实例只给本次选中Niagara、EffectType和显式PreloadAssets申请普通资源租约。没有把所有平台/画质变体视为必须成功的Runtime Bundle。元数据与执行资源所有权分离：ActiveUsers使根定义缓存不可提前淘汰，InstanceResources保持实际组件资源直到结束；停止/失败清理两种需求各一次，不能卸载其他World的资源。

缺选中变体时，bAllowFallback允许先试本定义基础Niagara，再经Data读取FallbackDefinition软引用的元数据，将其合法逻辑ID交还Data定义入口。不会同步加载，不把路径当逻辑ID，不绕过Data版本/类型/依赖校验。FallbackVisitedDefinitions拒绝重复身份，MaxDefinitionFallbackDepth（默认8、合法配置1..64）是结构安全限制而非CPU/GPU预算。缺定义本身时无法读取它的回退合同，明确失败；缺回退资产、非法身份、环、深度、参数或附着失效均形成可诊断失败。内部bUseBaseNiagaraSystem仅用于同定义基础重试，普通外部请求应为false。

Play的RequestId/ActivationId/PredictionKey关联预测，不是网络认证；World/Generation与唯一Id阻止旧句柄操作新实例。SemanticTag、ContextId、ContextTags及英雄/技能/皮肤/世界/平台/画质只用于表现资格；空值不猜测观察者身份。SpawnContext由中立事实提供空间/弱附着目标，Parameters必须符合定义白名单。Importance与既有设置只控制表现容量，不改变玩法结果。CompositeDepth内部递增，不是外部授权。

GetPlaybackSnapshot返回Loading、Playing、Completed、Cancelled、Failed或WorldDestroyed；Code保留具体拒绝/加载/执行失败，DefinitionId记录真实执行定义，Diagnostic保留回退或失败原因。完成处理器在本次组件/计时器/租约清理后一次通知；历史最多512个终态，淘汰后查询Invalid。非法/跨World/修改代次句柄不能停止真实实例。请求确认不会把加载/启动失败伪装为AlreadyCompleted。目录撤销后已经播放的实例保留其快照及租约直至结束，不直接卸载活跃资源；ContentRevoked枚举保留给明确因内容撤销终止的策略，本轮普通目录注销不生成该终态。

Preload使用独立Id/World/Generation，不转换成播放句柄、不生成组件。它为根/Composite必需子定义读取元数据，然后只预载本请求选中资源；全部成功才Ready。缺资源严格Failed，预载阶段不假装基础回退已经可播放。Ready继续持有自有定义/资源，CancelPreload或世界退出后全部释放；GetPreloadState提供Loading/Ready/Failed/Cancelled/WorldDestroyed与失败说明。Composite根配置同时约束最大总子定义和深度，重复定义需求去重；真实执行另按根MaxChildren累计所有后代出生数，子结束不返还总树预算。必需子失败取消根及兄弟，失效父不能遗留新定时器。

旧Catalog工具入口采用同P13：资格过滤、精确/显式父回退、Scope、六个等值项、显式Priority；ContextId/集合标签不计具体度。旧Specificity字段保留但不再影响排名。标准Gameplay不走第二套目录。NativeVFX原生回归先真实红灯（Scope顺序）后绿灯；Private/Tests的实际Registry、资源取消/旧代/终态用例仍需统一UE构建和Automation。真实Niagara/EffectType/关键预警基础资源尚未交付，不能声称游戏播放、GPU预算、5v5或Cook通过。

兼容目录的Catalog.Priority和Entry.Priority以64位加法形成显式Priority；原百万权重合成不再参与排序。旧工具目录需复核显式优先级配置，标准中立目录只使用Entry.Priority。

快照RequestId保留源请求发生身份；ParentHandle只在Composite子实例有效，根实例为空。监听完成的调用者可用完整Handle与ParentHandle区分根/子，不能仅凭共享RequestId把首个子完成当作整组完成。Submitted/Queued仅表示已受理，真正播放与最终失败须查询快照或完成通知。

## 独立复核后的生命周期补修

真实UE5.8.0 NiagaraComponent.cpp的OnSystemComplete先SetActiveFlag(false)，再OnSystemFinished.Broadcast。因此IsActive仅回答组件是否仍在播放，不能证明账本清理资格。私有Registry新增OwnsHandle按Id/Generation/World完整身份核账本；Cleanup、Stop与世界退出按该身份回收，组件自然不活跃仍需释放实例资源、定义使用计数、计时器、索引与去重。CleaningInstances保留递归清理栅栏，Registry移除和终态历史共同保证只通知一次。共享定义元数据成功缓存仍按World/LRU合同持有，ActiveUsers归零不自动卸载其他使用者需求。

Corrected替换先Stop旧实例；公开完成观察者可以同步Deinitialize、旅行或GC。Play捕获服务/World及初始化关闭世代，在Stop和执行返回后重新核对；关闭后返回InvalidWorld，不Reserve新实例、不Acquire替换租约、不复活去重。Deinitialize自身幂等，重入关闭由第一层清理负责。

CompositeRunner.Run及必需子受理/Timer登记返回bool；全部必需步骤先检查再排程，深度边界、非法步骤、子容量拒绝或无法登记定时器形成Failed并撤销整树，不能void早退后将父标Playing。延迟子实际拒绝由世界执行器传播到根；正常排程只表示时序开始，不宣称每个未来子资产已播放。结构限制与原项目伸缩配置不变，不新增假预算。

Private/Tests补自然先失活后Finished/重复完成、定义使用计数与实例归零、不活跃Stop/世界退出、纠正通知内关闭、Composite深度和必需子容量拒绝。GamePlatformVFXDataIntegrationTests只经公开Data真实服务申请：抽象UGamePlatformVFXDefinition作为IsA约束可以受理，实际缺注册Definition仍Failed；真实Play/Preload亦必须Queued/Loading后失败。另用已经加载的NiagaraComponent UClass作为普通软资源，按真实完成事件顺序核对自有Data租约Released及零计数；这不伪造Niagara System、Definition资产或GPU播放成功。测试是Transient边界夹具，所有UE用例尚未执行。Data允许抽象ExpectedClass的源修复归主执行者，本组没有访问/修改其Private。
