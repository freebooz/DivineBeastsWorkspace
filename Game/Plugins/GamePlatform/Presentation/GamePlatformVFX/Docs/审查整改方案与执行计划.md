# GamePlatformVFX 审查整改方案与执行计划

版本：0.2.0｜2026-09-30

## 一、审查结论

原 0.1.0 主体已经具备 ClientOnly、Niagara、Parameter Schema、Pooling、Scalability、Composite 和静态验证骨架，但存在四类关键问题：

1. GamePlatformPresentation 与 VFX Catalog/Resolver 双重语义真源；
2. VFX Definition 自建 UPrimaryDataAsset/Version/Revision，与 GamePlatformData Definition 体系分叉；
3. 私有 Streamable Definition Lease 绕过统一 Data Service；
4. Niagara 自然结束、MaxLifetime、Critical/Composite 预算与 Corrected 预测语义存在运行缺口。

## 二、执行计划及状态

### Phase 1：P0 架构收敛

- [x] DBAClient 显式启用 GamePlatformVFX；
- [x] Presentation DefinitionId 直达 VFX 执行器；
- [x] VFX Catalog/Resolver 降为兼容路径；
- [x] UGamePlatformVFXDefinition 继承 UGamePlatformDefinitionBase；
- [x] 删除 DefinitionId/Version/Revision 第二真源；
- [x] 正式 Definition 加载切换到 IGamePlatformDataService World Lease；
- [x] 退休 FGamePlatformVFXPreloadCoordinator。

### Phase 2：P1 生命周期与预算

- [x] Niagara Spawn 禁止自动激活，先登记与绑定 OnSystemFinished 再 Activate；
- [x] 自然结束即时回收实例、Dedupe 与 Definition Lease；
- [x] MaxLifetime 使用 Timer 真正执行；
- [x] 新增 HardMaxTrackedInstances；
- [x] Critical 不得突破 Hard Cap；
- [x] Composite Child 共用预算门禁；
- [x] World Deinitialize 释放全部租约和Timer。
- [x] Composite 父实例要求 `MaxTotalLifetimeSeconds > 0`，运行时与编辑器双重校验，避免无完成事件父实例永久残留；

### Phase 3：预测与行为语义

- [x] Corrected 状态对齐 Presentation；
- [x] RequestId 优先作为预测/确认/纠正去重键；
- [x] Provider 保留 Target/Impact 中立位置；
- [x] 非 Composite 收敛为 Generic Niagara 执行；
- [x] Attached 默认 Socket、Beam Source/Target、Area Radius 提供轻量通用适配；
- [ ] 中立 Attachment Anchor 契约：当前 Presentation Core 未定义，延期，不塞项目 UObject。

### Phase 4：端侧与健壮性

- [x] WorldSubsystem 限制 Game/PIE/GamePreview；
- [x] 排除 Dedicated Server/Commandlet；
- [x] 公共 Service 标记 Game Thread only；
