# SecurityRobustness（安全与健壮性）

Definition/Catalog视为可信Cook资产；运行Request仍必须受边界限制。公共Request不接收任意asset path、class path、remote script或Data Interface。

Parameter Schema限制名称、类型、数量、范围和Required参数；Catalog同级歧义Fail Closed；Handle比较Generation和World身份；Composite限制深度、子节点、延迟和总时长。

VFX永远不是安全/权限/Gameplay权威验证器。Required context只决定表现选择，不代替服务器授权。
