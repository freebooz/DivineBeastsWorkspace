# GamePlatformSurface 组件清单与使用说明

## 运行时组件

- `FGamePlatformSurfaceEnvironmentState（环境表面状态）`：跨游戏纯表现状态；有范围、单位、有限值校验与安全裁剪。
- `IGamePlatformSurfaceService（环境表面服务接口）`：C++稳定入口，提供 Apply／Get／Revision／Refresh 和状态变化订阅。
- `UGamePlatformSurfaceWorldSubsystem（环境表面世界子系统）`：私有实现；每客户端世界独立创建，无 Tick，负责去重、MPC绑定、更新和清理。
- `UGamePlatformSurfaceBlueprintLibrary（环境表面蓝图库）`：蓝图 Apply／Get／Refresh 入口，不拥有第二份状态。
- `UGamePlatformSurfaceSettings（环境表面配置）`：保存标准 MPC 软引用和诊断开关。

## 编辑器组件

- `FGamePlatformSurfaceAssetContract（表面资产合同）`：统一标准 MPC、八个稳定标量参数、必须／可选材质资产路径。
- `GamePlatformSurfaceEditor::EnsureCoreParameterCollection（核心MPC生成/验证）`：已有资产只验证；ValidateOnly 缺失即失败；创建模式仅首次创建并拒绝覆盖。
- `UGamePlatformSurfaceCoreAssetsCommandlet（核心资产命令）`：供人工／CI显式创建和验证真实 MPC；不生成假的空母材质。

## 标准MPC参数

- `GP_Surface_GlobalWetness`：0～1。
- `GP_Surface_GlobalSnowAmount`：0～1。
- `GP_Surface_GlobalSnowHeightCm`：厘米。
- `GP_Surface_GlobalMossInfluence`：0～1，默认1。
- `GP_Surface_GlobalPuddleAmount`：0～1。
- `GP_Surface_RainIntensity`：0～1。
- `GP_Surface_SnowIntensity`：0～1。
- `GP_Surface_TemperatureCelsius`：摄氏度，默认20。

项目层不得复制同义全局 MPC；项目局部差异留在 Material Instance（材质实例）。

## 材质资产组件

- `MF_GP_SlopeMask`：世界法线坡度遮罩。
- `MF_GP_HeightMask`：世界高度遮罩。
- `MF_GP_WorldNoise`：世界空间宏观噪声。
- `MF_GP_SnowLayer`：坡度×高度×噪声×局部积雪×全局积雪。
- `MF_GP_MossLayer`：坡度×宏微观噪声×局部苔藓×全局苔藓。
- `MF_GP_WetnessLayer`：颜色变暗、粗糙度降低、微法线平滑。
- `MF_GP_PuddleLayer`：水平／低洼区域低粗糙度积水。
- `M_GP_Surface_Master`：完整母材质；`M_GP_Surface_Lite`：低成本母材质。

## C++使用示例

```cpp
IGamePlatformSurfaceService* Surface = IGamePlatformSurfaceService::Get(*World);
if (Surface)
{
    FGamePlatformSurfaceEnvironmentState State;
    State.GlobalWetness = 0.8f;
    State.RainIntensity = 1.0f;
    Surface->ApplyEnvironmentState(State);
}
```

该调用只更新视觉。天气停止时由上游事实所有者提交新的完整状态。
