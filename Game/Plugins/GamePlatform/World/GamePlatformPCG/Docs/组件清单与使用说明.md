# GamePlatformPCG（游戏平台程序化内容生成插件）组件清单与使用说明

> 用途：供程序、TA（技术美术）、地编、美术和测试人员快速理解插件“包含什么、由谁使用、怎么使用、哪些能力尚未交付”。  
> 正式插件：`Game/Plugins/GamePlatform/World/GamePlatformPCG`。  
> 架构边界：只有 `GamePlatformPCG（共享运行模块） + GamePlatformPCGEditor（编辑器模块）`，不创建 ProjectPCG、DivineBeastsPCG 或 Core/Nodes/World 等平行空模块。  
> 状态说明：**已实现**=真实源码已落地但仍需本轮构建/测试证据；**现有基线**=0.1.0已有并继续保留；**合同已实现/资产未生成**=代码合同存在，但真实 .uasset 模板尚未由 Unreal Editor 生成；**接口**=只提供稳定扩展合同；**规划**=M2～M4后续能力，不能宣传为完成。
> 阅读方式：开发人员先查看“插件模块与现有运行基础”，TA（技术美术）重点查看 Definition（定义）、Template/Subgraph（模板/子图）和 Node（节点），地编重点查看 Actor（放置器）、Priority/Override（优先级/人工覆盖）及“开发人员最短使用路径”；测试人员重点查看当前实现状态、边界和 TestingAndEvidence（测试与证据）。

## 11. 神兽联盟项目层如何使用

平台层只提供机制；项目层建议按以下组合使用，不修改 GamePlatformPCG 底层：

```text
DBAWorlds（项目世界组合/校验）
        ↓
DBAWorldPack_Village / OpenWorld / MainArena
        ↓
Graph Instance + Data Asset + Child BP + 地图放置器
        ↓
GamePlatformPCG平台模板/节点/Definition
```

例如“湖心三岛桃花新手村”：

1. 在 `DBAWorldPack_Village` 创建 PeachForest/Forest/Farm/Road/Fence 等 **Data Asset实例**，类型仍使用平台 Definition。
2. 使用平台 `TPL_ScatterSurface / TPL_CropField / TPL_LinearDresser` 的 **Graph Instance**，不复制模板逻辑。
3. 创建 `AGamePlatformPCGVolumeActor / SplineActor / PolygonActor / ConnectorActor` 的项目 Child BP，仅配置默认DataAsset和表现，不创建新的PCG算法。
4. 地编在Village地图放置这些Actor并注册到唯一WorldDirector。
5. 先通过Schema/Template/Priority校验，再由Editor生成/Bake。
6. 碰撞、导航、资源锚点等玩法相关结果必须作为一致Bake结果进入Client/Server；纯装饰RuntimeDetail只允许客户端生成。

## 13. 开发人员最短使用路径

### 做一片森林

`BiomePreset → Layer → MeshSet + SpawnPolicy → TPL_ScatterSurface Graph Instance → VolumeActor → Exclusion/Priority → Editor Bake`。

### 做一块麦田

`CropProfile + ParcelPreset → TPL_CropField Graph Instance → PolygonActor → BuildRows → FieldFence/Gate → Editor Bake`。

### 做一条土路

`RoadProfile → TPL_LinearDresser Graph Instance → SplineActor → PriorityCarve树/作物 → TPL_InterfaceBand路肩 → Editor Bake`。

### 做田篱和门

`EnclosureProfile → Spline/Parcel边 → FitPostsToSpline → SelectSpanMeshByLength → BreakSpansByTags → ConnectorActor(Gate) → Editor Bake`。

### 做手工排除

放置 `AGamePlatformPCGExclusionActor`，设置来源和强度，由 `SG_PriorityCarve` 写 `Pcg.Exclude.Mask` 后进入 `PriorityCarve`。ManualLock使用最高优先级。

## 14. 不允许的用法

- 不新建 Core/Nodes/World/Network 等空模块。

- 不把P7/P8/P9或M2～M4规划能力写成已经交付。
