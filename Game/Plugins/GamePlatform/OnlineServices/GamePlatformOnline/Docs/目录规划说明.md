# GamePlatformOnline 插件目录与实施边界

本目录登记当前 `0.2.0` 规范插件的真实源码。插件仅包含 `GamePlatformOnline（跨端公共核心模块）` 与 `GamePlatformOnlineClient（客户端适配模块）`；原空 `GamePlatformOnlineServer（在线服务器模块）` 已移除，服务器控制面统一归 `GamePlatformServer（平台服务器插件）`。历史断点文档和旧测试输出仅作为证据，不构成当前目录设计。

```text
GamePlatformOnline/                                      # 在线认证、请求与资料服务插件唯一源码归属
├── GamePlatformOnline.uplugin                           # Runtime + ClientOnly 两模块；不含服务器空模块
├── README.md                                             # 当前能力、集成缺口和验证边界
├── Docs/                                                 # 安全证据和实现交接
│   ├── 目录规划说明.md                                  # 当前文件职责
│   ├── 安全断点记录.md                                  # 2026-09-21中断时的风险与历史测试结果
│   └── LegacyImplementationHandover.md                  # 原目录状态、接口约定及后续风险
├── Source/                                               # 唯一UE插件源码
│   ├── GamePlatformOnline/                               # 双端可用的契约与纯逻辑状态机
│   │   ├── GamePlatformOnline.Build.cs                   # Core、CoreUObject和GamePlatformCore公开依赖
│   │   ├── Public/                                       # 不暴露HTTP、JSON或原始令牌的稳定类型
│   │   │   ├── Interfaces/IGamePlatformOnlineService.h   # 显式游戏实例的在线门面声明
│   │   │   ├── Settings/GamePlatformOnlineConfiguration.h # 显式非敏感配置与安全预算
│   │   │   └── Types/                                    # 请求、认证、资料、结果和脱敏诊断
│   │   └── Private/                                      # 模块入口、实现和编译测试
│   │       ├── GamePlatformOnline.cpp                    # 当前模块注册入口

│   │       └── Tests/                                    # UE门面契约测试与受宏控制的原生行为测试
│   ├── GamePlatformOnlineClient/                         # 客户端UE适配、统一服务门面与私有Gateway传输
│   │   ├── GamePlatformOnlineClient.Build.cs             # 当前客户端模块规则
│   │   ├── Public/GamePlatformOnlineClientSubsystem.h    # Provider与快照公开声明
│   │   └── Private/                                      # 生命周期实现、模块入口与UE自动化测试
└── Tests/CMakeLists.txt                                  # 独立编译历史回归模型的原生测试入口
```

当前公共静态门面已经实现实例注册、反注册和配置校验；`UGamePlatformOnlineClientSubsystem（在线客户端子系统）` 实现 `IGamePlatformOnlineService（在线服务门面）` 并按 GameInstance 注册。客户端私有 Gateway 传输已接入 HTTP/JSON、安全重定向拒绝、流式正文预算、Token 私有保存和受保护请求。历史 `OnlineSession` 已通过编译期门禁限制为原生回归模型，不进入 UE 正式运行时，因此正式运行路径只有一套认证/请求状态机。原生测试与 UE 自动化测试分别证明不同边界，均不能替代真实 Gateway 联调与三目标构建。

迁移逐文件 SHA256 核对记录仅作为历史证据。当前工作区已检测并实际使用 CMake/CTest 与 `F:\\UnrealEngine-5.8.0-release` UE5.8 工具链：原生回归已重新构建并通过；UE 自动化与 Editor/Client/Server 三目标是否通过必须以本次最新构建和测试终态为准。生成产物只放 Saved/中间目录，不作为正式源码提交。
