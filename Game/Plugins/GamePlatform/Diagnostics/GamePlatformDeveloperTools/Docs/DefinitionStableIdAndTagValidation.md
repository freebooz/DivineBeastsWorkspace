# DefinitionStableIdAndTagValidation（定义、稳定ID与标签验证）

UGamePlatformDefinitionValidator按UGamePlatformDefinitionBase真实继承判断资格，调用ValidateDefinition校验LogicalId、规范主资产ID、DataVersion结构/内容修订与RequiredDefinitions。不会用类名包含Definition或旧DefinitionId/Version字段猜测合同；与全局聚合审计使用相同类型真源。

UGamePlatformStableIdValidator对平台主资产使用LogicalId形成的规范主资产身份，版本分隔符服从Core解析合同；其他遗留一方类型继续按已声明字段检查字符，不将引用重复视为多个所有者。全局唯一所有者索引以主资产ID建立；缺失/重复/失败定义与依赖环都会明确失败。

UGamePlatformGameplayTagValidator 遍历 FGameplayTag/FGameplayTagContainer。默认拒绝已取消的 FiveCamp、Faction、Element、KingSeal 前缀；项目可通过 UGamePlatformValidationSettings 覆盖。

跨资产duplicate ID、RequiredDefinitions cycle等由项目级全量审计补充，图检查用显式栈。元数据继承集合筛选后才加载定义，Editor大内容库耗时/内存须实测。DefinitionIdentityContract新增内存对象回归，同时检查逐资产与全局入口；未保存uasset，测试编译不等于真实运行通过。
