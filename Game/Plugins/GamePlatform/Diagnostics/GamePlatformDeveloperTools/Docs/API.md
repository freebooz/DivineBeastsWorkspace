# API（接口）

主要公共类型：
- FGamePlatformValidationRule（验证规则）。
- FGamePlatformValidationResult（验证结果）。
- FGamePlatformValidationAllowlistEntry（临时豁免项）。
- FGamePlatformValidationService（规则注册、报告、脱敏、路径安全）。
- UGamePlatformNamingValidator（命名验证器）。
- UGamePlatformContentValidator（内容验证器）。
- UGamePlatformDefinitionValidator（Definition验证器）。
- UGamePlatformStableIdValidator（稳定ID验证器）。
- UGamePlatformGameplayTagValidator（玩法标签验证器）。
- UGamePlatformServerAssetSafetyValidator（服务器资产安全验证器）。
- UGamePlatformDependencyValidator（三层依赖验证器）。
- UGamePlatformClientLeakValidator / UGamePlatformServerLeakValidator（端侧泄漏验证器）。
- UGamePlatformRPCAndAuthorityValidator（RPC/Authority静态验证器）。
- FGamePlatformAssetAudit（资产审计）。
- UGamePlatformReviewSubsystem / Case / Report（人工验收）。
- UGamePlatformPerformanceTestRunner（性能测试运行器）。
- UGamePlatformValidationCommandlet（自定义命令行验证）。
