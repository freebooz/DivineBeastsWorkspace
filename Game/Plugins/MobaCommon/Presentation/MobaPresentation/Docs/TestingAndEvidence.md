# TestingAndEvidence（测试与证据）

源码包含Runtime语义注册表/Request Builder自动化测试和Client Ability/Critical/Status适配测试；PowerShell验证脚本覆盖语义、Arena、Combat、Travel边界。

静态验证只能证明目录、依赖、Tag、禁止项和关键代码路径存在，不能证明UE5.8编译、Multi-PIE、ClientTravel、1v1/5v5实际运行或Cook资源剥离。

真实Client/Server Cook工件未提供时，Cook状态必须为“未执行”。ManualReview（人工审查）必须由真实Reviewer完成。
