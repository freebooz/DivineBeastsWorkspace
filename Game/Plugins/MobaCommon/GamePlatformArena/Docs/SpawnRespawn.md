# SpawnRespawn（出生与复活）

Arena只决定Which Spawn Group/When（使用哪个出生组与何时出生）。`IGamePlatformArenaGameplayLifecycleAdapter（玩法生命周期适配接口）` 将Spawn/Respawn请求交给现有Gameplay/Character权威生命周期实现。

死亡事实来自Combat（战斗）权威事件，Arena不直接SetHealth（设置生命值）或Revive（复活）。标准复活延迟当前为可配置默认值，策略ID来自ArenaModeDefinition。
2026-10-09第二轮合同补充：IGamePlatformArenaGameplayLifecycleAdapter新增纯虚只读CapturePlayerGameplayOwnership(PlayerId,OutOwnership)。仅游戏线程调用；成功提供本装配当前受控Pawn弱引用与正AvatarGeneration，不拥有/授权Pawn，不代表Ready或Active。已准入重连尚无Pawn时可为空且保留最后签发代次；缺世界、连接、合法代次或当前拥有关系时false并清空输出。所有实现必须真实检查，不能默认固定成功；项目Adapter及两个明确测试端口已经同步。

GameMode.SetGameplayLifecycleAdapter仅实际替换借用者时签发新BindingId，清空即失效；GetGameplayLifecycleBindingId与IsGameplayLifecycleAdapter只读核预期指针和绑定代次，地址复用不能授权旧命令。GetMatchPhase读取真实权威阶段，复制GameState视图不能单独批准出生。

死亡统计同步通知之后，以及外部失活/复活受理返回之后，GameMode核同World、Match/Server、阶段、BindingId、当前PlayerState与Pawn/Controller/代次。结束/退出正常撤销后续动作。项目复活Timer捕获原请求完整上下文，先核RequestId才移除自身记录，到期不满足InProgress或原拥有关系时取消而不出生。出生点、Restart、Character初始化/预热及激活边界都再次核原上下文。Timer受理不代表到期出生成功。第二轮新增行为命令仍未执行引擎Automation；五模式生产配置继续NotConfigured。
