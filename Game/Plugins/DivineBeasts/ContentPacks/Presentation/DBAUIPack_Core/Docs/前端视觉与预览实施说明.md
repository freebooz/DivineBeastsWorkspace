## 三层归属及依赖

平台层GamePlatformUI提供中立页面、层栈和本地玩家界面服务；本次不向平台加入生肖、品牌、登录业务或项目资产路径。MobaCommon为可选MOBA扩展，本次公共登录和角色页面不新增对它的依赖。第三层DBAClient的DivineBeastsUIClient拥有页面原生类、只读ViewModel、统一命令端口及流程适配；第三层纯内容包DBAUIPack_Core只持有布局、纹理和品牌图源，向下使用既有原生基类。

LOGO与背景源文件为SourceArt/UI/DBA_MythicLogo.png和DBA_MythicLogin.png；真实纹理为/DBAUIPack_Core/UI/Textures/DBA_MythicLogo及DBA_MythicLogin。当前正式LOGO采用用户2026-10-08最新提供的青龙白虎图片：1254×1254、RGBA、透明度范围0—255，源文件与附件SHA256一致，未经重绘、裁切或变形。登录页左上按224×224逻辑像素等比显示，保持既有纹理和挂载点身份。Monolith的editor.import_texture导入真实引擎资产；Widget布局、命名控件、样式、密码遮罩、Tab导航、编译、保存与结构回读统一使用Monolith。普通文件工具仅维护图源、JSON布局说明、C++、脚本与本说明。
