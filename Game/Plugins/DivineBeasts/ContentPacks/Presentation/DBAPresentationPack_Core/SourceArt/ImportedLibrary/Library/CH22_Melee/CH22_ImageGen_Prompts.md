# CH22 Melee 图像生成补充提示词

统一方向：高饱和青蓝、橙红、白炽核心；斩击凌厉、爆发、冲击强。

统一硬约束：严格使用下列文件名与尺寸；2 次幂；移动端、Mip 与 ASTC/ETC 压缩安全；
透明表现图使用真实直通 Alpha、四角透明、四周至少 10% 留白、透明区 RGB=0；
数据图使用纯黑底白灰单通道、线性工作流、无无意义 Alpha；Noise/Flow 必须无缝；
无文字、无水印、无边框、无场景、无地面、无 UI、无相机透视、无 1px 高频细节。
