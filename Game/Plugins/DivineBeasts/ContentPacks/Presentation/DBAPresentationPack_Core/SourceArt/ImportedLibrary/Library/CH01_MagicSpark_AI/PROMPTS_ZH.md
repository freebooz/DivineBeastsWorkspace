# CH01 Magic Spark AI 纹理生成提示词（中文补充版）

## 通用关键补充词

将下面内容追加到每条原始纹理提示词末尾。生成工具无法严格控制尺寸或透明通道时，仍须在后处理阶段按本文件验收。

```text
用途：Unreal Engine 5 Niagara 粒子纹理，移动端兼容，适用于 Additive / Unlit VFX 材质。
输出格式：8-bit PNG；火花、星芒、拖尾和径向光必须为 RGBA，使用 Straight Alpha（非预乘 Alpha）；噪声和扭曲图为不带 Alpha 的单通道灰度图。
尺寸：主火花 1024×1024；高速拖尾 1024×512；星芒、径向光、噪声和扭曲图 512×512。所有尺寸必须是 2 的幂，以便 Unreal 生成完整 Mip 链。
透明要求：Sprite 四角 Alpha 必须为 0，背景必须真正透明；禁止把黑色、白色或棋盘格烘焙进 RGB。主体与画布边缘至少保留 10%～16% 的完全透明留白，不允许光芒被裁切或接触边缘。
边缘要求：使用平滑抗锯齿 Alpha；主体边缘不得出现绿色/洋红色抠图污染、黑边、白色硬边、方形透明边界或预乘 Alpha 光晕。
移动端要求：主体在 64px～128px 预览尺寸仍可识别；主要亮线在最终 512px 图上建议至少 2～3 像素宽；减少无意义的大面积低 Alpha 雾层，限制透明过绘；避免单像素噪点和在 ASTC/ETC2 压缩后会闪烁的超高频细节。
构图要求：每张图仅包含一个功能明确的 VFX 元素；中心、朝向和留白稳定；不包含文字、水印、边框、场景、地面、投影、镜头污渍或任何可识别物体。
色彩要求：效果本体仅使用白色到灰色的亮度信息，实际颜色由 Niagara Particle Color 和材质参数控制；禁止生成彩色光晕。
```

## 透明 Sprite 的生成补充词

```text
优先直接生成透明背景 RGBA PNG。若模型不支持原生透明，则使用完全均匀的纯 #00FF00 键色背景：背景不得含渐变、纹理、阴影、反射或光照变化，效果主体不得包含绿色；生成后必须抠图、去绿边并验证四角透明。不要把查看器显示的黑色误认为已烘焙黑底，应检查实际 Alpha 通道。
```

