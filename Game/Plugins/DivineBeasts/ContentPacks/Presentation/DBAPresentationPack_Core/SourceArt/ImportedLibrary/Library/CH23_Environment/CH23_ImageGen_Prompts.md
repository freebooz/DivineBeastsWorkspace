# CH23 Environment 图像生成补充提示词

统一方向：暴雨蓝、风暴紫、陨火橙红、星落金白；环境尺度明确、冲击强、轮廓清楚。

统一硬约束：严格使用目标文件名与尺寸；2 次幂；移动端、Mip、ASTC/ETC 压缩安全；
透明表现图使用真实直通 Alpha，四角透明、四周至少 10% 留白、透明区 RGB=0；
数据图使用纯黑底白灰单通道、线性空间、无多余 Alpha；Noise 必须四边无缝；
无文字、无水印、无边框、无场景、无地面、无 UI、无相机透视、无 1px 高频细节。
