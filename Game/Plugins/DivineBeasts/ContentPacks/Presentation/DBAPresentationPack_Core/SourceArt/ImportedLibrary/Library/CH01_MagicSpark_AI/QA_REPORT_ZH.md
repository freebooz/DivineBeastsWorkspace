# 质量验收报告

验收日期：2026-08-13

## 自动检查

- 纹理数量：10 张最终 PNG。
- 尺寸：2×1024²、1×1024×512、7×512²，全部为 2 次幂。
- 透明纹理：7 张，均为 RGBA；四角 Alpha=0；Alpha 最小值=0、最大值约为 1。
- 灰度纹理：3 张，均为不透明单通道 Gray，无多余 Alpha。
- 无缝边缘：Noise Soft、Noise Perlin、Distortion 的左右与上下边缘 RMSE 均为 0。
- Streak 有效 Alpha 边界：801×186，位于 1024×512 画布的安全区内。

## 人工视觉检查

- 主火花与 Sharp 火花在深色背景下轮廓清楚，没有方形透明边界。
- Glint4/Glint6 核心紧凑，低分辨率下仍可区分。
- Streak 朝向明确，透明覆盖区域小，适合 Velocity Aligned Sprite。
- RadialSoft 可作为外围柔光；Radial 带明显暗环，更适合瞬时冲击波或核心层，不建议替代纯柔光。
- 镜像无缝噪声具有对称结构；用于快速滚动、扭曲和短时粒子时不明显，不建议直接用于大面积静态表面。

## UE 导入验收门槛

本报告只验证源 PNG。实际导入 Unreal 后仍须检查：

1. Sprite 的 `has_alpha=true`，不得变成 `G8`。
2. 1024² 应产生 11 级 Mip，512² 应产生 10 级 Mip，1024×512 应产生完整矩形 Mip 链。
3. 材质 Opacity 必须读取 Texture A，而不是用 R 通道代替。
4. 在移动预览渲染器中检查 ASTC/ETC2 边缘、Bloom 和透明过绘。
