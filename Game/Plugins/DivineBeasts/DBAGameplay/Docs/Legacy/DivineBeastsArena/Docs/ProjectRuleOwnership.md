# ProjectRuleOwnership（项目规则所有权）

平台GamePlatformArena拥有通用Phase、Assignment、Roster、Selection、Ready、Countdown、GameState/PlayerState复制、Reconnect、Forfeit、Result提交框架。

DivineBeastsArena只拥有神兽联盟五模式实际Production配置、项目Revision/Content/HeroCatalog一致性、生肖Hero资格和必要的ApplicationFlow/Server项目适配。

未批准规则不属于“默认平台值即项目值”。当前Platform FoundationTest Map、900秒、Standard score/win、5秒respawn只能视为平台开发默认，禁止进入项目Shipping。
