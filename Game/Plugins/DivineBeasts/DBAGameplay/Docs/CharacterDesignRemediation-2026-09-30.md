# 项目角色资源与资格组合（2026-09-30）

DivineBeastsCharactersRuntime属于项目层，双端游戏线程运行。CharacterComponent消费服务器可信身份/SpawnGeneration/AvatarGeneration，拥有本组件Definition资源租约、加载代次、只读资格Gate注册及Avatar事件句柄；不拥有ASC、权威玩法状态、伤害或第二个资产管理器。

Catalog.AcquireDefinitionResources沿用旧英雄PrimaryAssetId并调用平台HeroDefinitionLoader/Data普通资源API。CharacterComponent保存完整签发租约，完成核对弱组件、ScopeId/LeaseId/Generation、加载代次及角色代次；成功后持续持有至EndPlay、身份或原子复制状态变化。失败保存LastDefinitionLoadResult、撤销本请求需求并保持未Ready；EndPlay先阻断新的初始化/Gate请求，撤销Gate并解绑，随后释放租约。正式scoped路径不使用旧RequestDefinition的非Shipping临时开发回退：缺真实Definition资产是明确失败。这可能使原来只靠开发回退的工程路径停止Ready，需配置真实已登记资产；不得伪造成功。

组件BeginPlay/初始化与Readiness变化发现当前Pawn/Controller/PlayerState上的平台ASC，并订阅OnAvatarBindingChanged。ASC在新ActorInfo建立之后广播，组件重新注入捕获当前项目代次的FDivineBeastsCharacterActivationGate；Avatar不属此组件时不注入。Gate每次读取真实CharacterReady、Pawn/Controller/PlayerState/ASC Owner，复制PlayerState的Active/ControlledPawn、SpawnGeneration及PawnGeneration，再由服务器GameMode.IsPlayerGameplayActive确认；客户端只允许本地拥有者预测尝试。默认、缺失、过期、未Active、远端预测均失败关闭。

项目Context.AvatarGeneration对应PlayerState.PawnGeneration；ASC本地AvatarGeneration属于ASC独立绑定作用域，不混用。组件不代替宿主调用BindAbilityActorInfo。当前DBA玩家宿主源码尚未发现该ActorInfo绑定调用（除测试），因此门禁实际接线已建立但端到端技能仍不可宣称可用。NPC没有PlayerState/准入快照必须接独立可信策略，不能用固定成功绕过。

新增公开Data依赖用于返回结果/租约值，私有Gameplay依赖用于Gate真实事实读取；DBAGameplay插件描述依赖由主执行者统一维护。Catalog、Creation及ArenaWarmup其他资源消费者由主执行者单独负责。

测试DivineBeastsCharacterActivationLifecycleTests仅用真实ASC/Pawn与未就绪角色核对注入、换Avatar重注入和EndPlay撤销；未Ready不注入固定成功。UE Automation/客户端服务器联机/内容版本与资产缺失运行未由Task3执行。文件范围为CharacterComponent公开头和私有实现、私有Abilities Gate、CharactersRuntime.Build.cs及Private/Tests，存量逐字段中文说明仍需持续审核，不能宣称整个DBAGameplay已完整合规。

AI/NPC控制器上的Pawn不注入玩家Gate，避免抢占GamePlatformAIController的中立服务器Gate；AI资格由真实Brain/Data/占有/代次事实决定，不依赖项目玩家PlayerState。

NoPCH实际编译补正：公开/实现直接调用FGamePlatformResult的模块增加直接Public GamePlatformCore依赖；成员调用处直接包含完整Actor头，不依靠PCH或Unity来源掩盖类型/链接所有权。插件描述对应依赖由主执行者同步，统一复编尚待完成。
