# DBAArena 用户界面设计（神兽联盟竞技UI）

> 插件：DBAArena（神兽联盟可选竞技插件）
> 模块：DivineBeastsArenaClient（神兽联盟竞技客户端模块）
> 依赖方向：DBAArena → GamePlatformArenaClient → GamePlatformUIClient

## 1. 所有权

DBAArena 独立拥有所有 Arena（竞技）专属 UI，DBAClient 不注册这些表面：

- UI.Screen.Matchmaking（匹配）。
- UI.Screen.MatchFoundReady（匹配成功准备）。
- UI.Screen.ArenaHeroSelection（竞技英雄选择）。
- UI.Screen.Scoreboard（竞技记分板）。
- UI.Screen.PostMatchResult（赛后结算）。
- UI.HUD.Arena（竞技HUD）。

关闭 DBAArena 后，公共客户端仍可独立登录、进入世界、使用背包/任务等非竞技界面。

## 2. 继承

```text
UGamePlatformUIScreen
└── UGamePlatformMobaArenaScreenBase
    └── UDivineBeastsArenaScreenBase
        ├── UDivineBeastsMatchmakingScreen
        ├── UDivineBeastsArenaHeroSelectionScreen
        ├── UDivineBeastsScoreboardScreen
        └── UDivineBeastsPostMatchResultScreen

UGamePlatformModalScreen
└── UGamePlatformMobaArenaModalScreenBase
    └── UDivineBeastsMatchFoundReadyScreen

UGamePlatformHUDWidget
└── UGamePlatformMobaArenaHUDBase
    └── UDivineBeastsArenaHUD
```

## 3. ViewModel 与事件

`UDivineBeastsArenaUIClientSubsystem（竞技UI本地玩家子系统）`：

- LocalPlayer（本地玩家）作用域。
- 持有 `UGamePlatformArenaViewModel（MOBA通用竞技视图模型）`。
- 订阅 Arena GameState 的 Phase/Team/Result（阶段/队伍/结果）复制事件。
- 订阅最多10名 Arena PlayerState 的 Stats（统计）事件。
- 不使用 Tick。
- 不实现匹配算法、MMR、胜负、比分等权威规则。

## 4. PC / Mobile

资源规划：

```text
/DBAArena/UI/Screens/WBP_DBA_UI_Arena_<Name>
/DBAArena/UI/Screens/WBP_DBA_UI_Arena_<Name>_Mobile
/DBAArena/UI/HUD/WBP_DBA_UI_ArenaHUD
/DBAArena/UI/HUD/WBP_DBA_UI_ArenaHUD_Mobile
```

PC 与 Mobile 共用 ScreenId、Arena ViewModel、Definition 和状态事件。
