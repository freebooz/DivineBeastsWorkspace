# DBAArena 用户界面设计（神兽联盟竞技UI）

> 插件：DBAArena（神兽联盟可选竞技插件）
> 模块：DivineBeastsArenaClient（神兽联盟竞技客户端模块）
> 依赖方向：DBAArena → GamePlatformArenaClient → GamePlatformUIClient

## 1. 所有权

DBAArena 独立拥有所有 Arena（竞技）专属 UI，DBAClient 不注册这些表面：

- UI.Screen.Matchmaking（匹配）。
- UI.Screen.MatchFoundReady（匹配成功准备）。
- UI.Screen.ArenaHeroSelection（竞技英雄选择）。
- UI.Screen.Scoreboard（竞技记分板）。
- UI.Screen.PostMatchResult（赛后结算）。
- UI.HUD.Arena（竞技HUD）。

关闭 DBAArena 后，公共客户端仍可独立登录、进入世界、使用背包/任务等非竞技界面。

## 3. ViewModel 与事件

`UDivineBeastsArenaUIClientSubsystem（竞技UI本地玩家子系统）`：

- LocalPlayer（本地玩家）作用域。
- 持有 `UGamePlatformArenaViewModel（MOBA通用竞技视图模型）`。
- 订阅 Arena GameState 的 Phase/Team/Result（阶段/队伍/结果）复制事件。
- 订阅最多10名 Arena PlayerState 的 Stats（统计）事件。
- 不使用 Tick。
- 不实现匹配算法、MMR、胜负、比分等权威规则。

### 2026-10-09 竞技蓝图制作目录与状态

- 竞技专属`WBP_DBA_UI_Arena_Matchmaking`（竞技匹配）、`WBP_DBA_UI_Arena_MatchFoundReady`（准备确认）、`WBP_DBA_UI_Arena_HeroSelection`（英雄选择）、`WBP_DBA_UI_Arena_Scoreboard`（记分板）、`WBP_DBA_UI_Arena_PostMatch`（赛后结算），归`/DBAArena/UI/Screens/`。
- `WBP_DBA_UI_ArenaHUD`（竞技HUD）归`/DBAArena/UI/HUD/`，由`DivineBeastsArenaHUD`（第三层竞技HUD基类）派生；它的上层为`GamePlatformMobaArenaHUDBase`（MOBA通用HUD），最终继承平台`GamePlatformHUDWidget`（通用HUD）。
- `Game/Source/DivineBeastsArenaEditor.Target.cs`显式启用DBAArena，使编辑器能加载专属父类；`DivineBeastsArenaServer.Target.cs`保持ServerOnly与客户端视觉剥离，客户端正式Target已有DBAArena。
- 6份竞技规格位于`Saved/Monolith/GameUIComponentSpecs/Arena_*.json`与`ArenaHUD.json`；若未完成Monolith真实资产操作，蓝图状态为**待制作**，不可登记成已交付。
- 通用倒计时、队伍血条、头像和技能快捷栏依赖GamePlatformUI的新基础组件，不允许在DBAArena再实现相同平台渲染机制。竞技比分与比赛阶段仍来自`UGamePlatformArenaViewModel`（MOBA竞技只读视图模型）。
- 交付时逐项验证焦点控件ModeList/ReadyButton/HeroList/ScoreboardList/ReturnWorldButton，以及赛事1v1～5v5、快速切换与赛后返回世界。使用Monolith保存后才更新真实资源验证记录。

## 2026-10-09 3A竞技UI参考项归属

- `DBAClient/Docs/3A游戏UI十大业务域组件总清单_V1.0.md`中的Arena（竞技对局）包含匹配队列、准备、选人、阵容、倒计时、比分、记分板、击败播报、复活时间、地图目标、投降、掉线、观战、回放、战绩及赛后结算等目标UI组件。
- Buff（增益）、Debuff（减益）、CC（控制）、冷却、首领/比赛关键机制视觉复用第一层`GamePlatformUI`公共状态组件；比赛规则相关排序、目标公开范围、队友技能信息和观战延迟归MOBA竞技只读事实；`DBAArena`只实施第三层赛事UI组合与视觉资源。
- 不在DBAArena重新定义Buff/Debuff/计时器权威状态，也不把世界/账号通用UI强制依赖竞技插件。尚未登记为真实Surface或编译的规划项不要标记为已实现。

## 5. 2026-10-09 竞技UI状态与生命周期接线

- `UDivineBeastsArenaUIClientSubsystem`（竞技界面本地玩家子系统）从通用竞技ViewModel的状态事件刷新项目竞技页面。公共Login/World页面仍归DBAClient管理；竞技只跟踪自己的屏幕请求和HUD实例。
- 匹配、准备、竞技选人和赛后结算通过GamePlatformUIManager的异步页面API申请显示，等待成功后关闭本竞技域旧页面。外部状态变化时取消过期请求；资源失败缓存当前SurfaceId，避免复制事件不断发起失败加载。
- 竞技HUD由DBAArena独立异步加载、绑定UGamePlatformArenaViewModel、挂载HUD层；离开竞技世界、切换控制器、状态变化及子系统退出时取消HUD加载、卸载实例、释放自身资源租约。
- `Scoreboard`（记分板）仍属于竞技专属次级界面，当前只具备定义、父类和数据契约，手动显隐输入以及真正控件蓝图待后续补齐。全部6项竞技蓝图当前未交付，不能声称运行闭环通过。
- 不使用业务Widget Tick；后续验证必须覆盖同步失败、异步回调迟到、快速切换、1v1~5v5及新世界生命周期。
