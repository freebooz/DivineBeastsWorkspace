# 神兽联盟用户界面目录规划（人工审核基线）

> 状态：当前有效
> 日期：2026-09-27
> 适用引擎：Unreal Engine 5.8
> 目标：锁定 GamePlatformUI（游戏平台公共UI）→ MobaCommon（MOBA通用UI）→ DBAClient/DBAArena（神兽联盟项目UI）的依赖、继承、目录和界面所有权。

## 1. 分层结论

```text
GamePlatformUI（跨游戏公共UI机制）
        ↓
GamePlatformArenaClient（MOBA通用竞技UI）
        ↓
DBAClient / DivineBeastsUIClient（公共非竞技UI）
        +
DBAArena / DivineBeastsArenaClient（可选竞技UI）
        ↓
Widget Blueprint / Definition / Style（控件蓝图/定义/样式）
```

强制规则：

1. 公共机制尽量下沉 GamePlatformUI，不放神兽联盟业务语义。
2. MOBA 竞技共性放 GamePlatformArenaClient，不创建第二套 MobaUI 插件。
3. DBAClient 不依赖 DBAArena；关闭 DBAArena 后登录、世界、背包、任务、系统等公共客户端仍可运行。
4. Arena HUD、匹配、准备、英雄选择、记分板、赛后结果只归 DBAArena。
5. UI 更新使用 ViewModel/领域事件；禁止业务 Widget Tick（逐帧轮询）。
6. PC、手柄、Touch（触控）和 Mobile（移动端）共享状态、ViewModel、Definition；只在布局差异很大时使用 Widget Variant（控件变体）。
7. C++ 按继承/机制组织，Content（资源）按业务域组织。
8. `.uasset` / Widget Blueprint 必须由 Unreal Editor（虚幻编辑器）合法创建，不伪造二进制资源。

## 9. 更新事件与性能

```text
领域事实 / Snapshot（快照）
        ↓
领域Client / Adapter（客户端/适配器）
        ↓
ViewModel / DTO（视图模型/数据对象）
        ↓
Typed Delegate（类型化事件）
        ↓
Screen / HUD / Panel / Feedback / Notification
```

- 禁止 Widget Tick 轮询血量、背包、任务、匹配。
- 禁止 UI 直接修改 Gameplay 权威状态。
- 禁止业务模块直接 AddToViewport（添加到视口）。
- Feedback（反馈）活动上限48，池上限64，近期 OccurrenceId（发生标识）去重上限256。
- WorldUI（世界UI）活动上限128，池上限128；仅活动时30Hz集中投影，空闲停止。
- Inventory（背包）使用平台 GetViewModelsView() 缓存。
- Quest（任务）使用平台 GetSortedSnapshotsView() 缓存。
- PC/Mobile（桌面/移动）共享状态和ViewModel。

## 10. 真实资产状态与后续门禁

`DBAUIPack_Core` 已作为纯内容插件登记。公共 RootLayout 与登录页按 `/DBAUIPack_Core/UI/...` 路径由 Monolith MCP 创建、编译、保存并回读；其完成状态以 `DBAUIPack_Core/Docs/MonolithGenerationManifest.json` 和真实引擎资产为准。其余 Widget Blueprint、Definition DataAsset、Style/Theme、Icon/Font 仍须按需通过 Unreal Editor/Monolith 创建，并执行 Multi-PIE、Android/iOS、安全区、Cook 和 Unreal Insights 验收。
