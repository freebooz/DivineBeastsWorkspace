# ProjectCatalog（项目目录）

FDivineBeastsPresentationProjectCatalog当前提供Revision=1的项目默认目录片段，只包含跨World/Village共用的两个默认映射。

目录条目包含SemanticTag、ContextQuery、ProviderChannel、DefinitionId、Scope、Specificity、Priority、ContentRevision。

当前ProviderChannel使用逻辑VFX通道，DefinitionId为Presentation.DBA.*逻辑ID，不是Niagara/System/Asset Path。

Project Catalog不是所有项目资源总表。Hero、World、Skin等具体覆盖应由对应Content Pack片段注册；当前实际Content Pack为0，所以覆盖资产状态为“未执行”。
