# UIContentPackAndStyling（UI内容包与样式）

目标公共UI美术包为 DBAUIPack_Core（神兽联盟公共UI资产包），只承载真正跨页面复用的：

- common style（公共样式）
- buttons（按钮）
- dialogs（对话框）
- HUD common（公共HUD）
- icons（图标）
- brushes/materials（画刷/材质）
- input prompts（输入提示）

Hero-specific（英雄专属）UI资源归Hero Pack；World-specific（世界专属）资源归World Pack；Skin-specific（皮肤专属）资源归Skin Pack。

当前工作树没有真实 DBAUIPack_Core、Hero/World/Skin UI Pack，也没有任何项目UI .uasset，因此内容包迁移和样式Cook状态为“未执行”。

Source目录没有图片、字体或视觉二进制资源。
