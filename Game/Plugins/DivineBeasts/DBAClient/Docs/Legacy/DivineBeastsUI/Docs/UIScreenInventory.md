# UIScreenInventory（一期页面清单）

当前源码清单共19个UI Surface（界面表面），其中13个Screen（页面）、5个HUD（抬头显示）和1个Notification（通知）。

正式Screen ID：

1. UI.Screen.Boot（启动）
2. UI.Screen.Login（登录）
3. UI.Screen.CharacterRoster（角色列表）
4. UI.Screen.CharacterCreate（角色创建）
5. UI.Screen.CharacterSelect（角色选择）
6. UI.Screen.LoadingTravel（加载/切服）
7. UI.Screen.ErrorReconnect（错误/重连）
8. UI.Screen.Matchmaking（匹配）
9. UI.Screen.MatchFoundReady（匹配成功/准备）
10. UI.Screen.ArenaHeroSelection（竞技英雄选择）
11. UI.Screen.Scoreboard（计分板）
12. UI.Screen.PostMatchResult（赛后结果）
13. UI.Screen.SystemMenu（系统菜单）

HUD：

- UI.HUD.OpenWorld（开放世界HUD）
- UI.HUD.VillageMain（新手村HUD）
- UI.HUD.TutorialGuidance（教学引导）
- UI.HUD.TrainingControls（训练控制）
- UI.HUD.Arena（竞技HUD）

Notification：

- UI.Notification.Toast（短提示）

当前一期没有已批准 Settings（设置）页面，因此源码和自动化明确不擅自创建 UI.Screen.Settings。
