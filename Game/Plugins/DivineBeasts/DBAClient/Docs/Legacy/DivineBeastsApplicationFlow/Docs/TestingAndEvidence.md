# TestingAndEvidence（测试与证据）

C++源码新增 Automation（自动化）测试覆盖平台Node注册/重复拒绝、FlowRunId、NodeGeneration、Stale Operation、项目类型边界和Arena Extension注册/注销。

PowerShell专项门禁覆盖ClientOnly模块与依赖、旧业务字段、角色契约与幂等结构、五类World Entry、TransferTicket/Session/Loading边界、重连/账号切换安全。

Shared Contract验证和clean regenerate用于证明项目契约与Generated代码未漂移。

静态源码检查不等于UE5.8编译、Automation运行、Client Cook或真实E2E。综合脚本会单独报告这些状态。
