# 十大业务域的通用UI组件与三层装配清单

2026-10-09。实际页面/组件情况必须分为 C++基类、视觉Blueprint、业务数据接线、UE编译/PIE/Cook 五个独立验收口径。

## 一、三层责任

- `GamePlatformUIClient`（平台底座）：复用资源条、头像、槽位、技能/快捷栏、小地图、组队、倒计时、状态效果、任务追踪、交互提示、设置单项、悬浮提示，以及通知、世界标记、反馈、输入适配和页面管理。
- `GamePlatformArenaClient`（MOBA通用层）：复用竞技HUD、匹配/准备/英雄选取/记分板和比赛只读ViewModel。平台层不得引用竞技类型。
- `DivineBeastsUIClient`（神兽联盟公共项目层）：账号、角色、世界、背包、战斗、社交、系统、运营等领域页面、状态适配和三维预览；具体国风Widget归`DBAUIPack_Core`。
- `DivineBeastsArenaClient`（项目竞技层）：竞技专属蓝图归`DBAArena/Content/UI/`，不进入公共登录或新手村依赖闭包。

## 2026-10-09 3A游戏界面能力总库

- 原有十大业务域的**分类不变**，研究清单新增`Docs/3A游戏UI十大业务域组件总清单_V1.0.md`（263个候选UI能力），机器台账为`Docs/AAAUIComponentInventoryV1.json`。
- 状态效果体系不拆新插件：Combat UI（战斗域）拥有Buff（增益）、Debuff（减益）及硬控/免疫/驱散等基本显示分类，统一基于现有`GamePlatformStatusEffectTrayWidget`（游戏平台状态托盘）按配置分组；世界、队友和竞技仅组合可见性授权的只读投影。专项设计见`GamePlatformUI/Docs/AAA状态效果UI设计规范_V1.0.md`。
- 典型AAA参考范围：玩家/目标/焦点/首领生命与施法、技能冷却、增减益优先级、首领关键机制时间轴、任务/世界地图、装备对比、组队/聊天、对局统计、HUD布局编辑、运营活动等；不应仅将一个抽象C++类型误当作完整视觉页面。
- 新清单按P0/P1/P2分期、标明已有C++机制与待制作蓝图；不改变当前六个真实Widget和32份Monolith视觉规格的历史状态。

## 二、插件实际组件清单

1. 生命/护盾/气势：`GamePlatformResourceBarWidget`（通用资源条）和`DivineBeastsPlayerStatusPanel`（项目状态面板）。
2. 头像/英雄肖像：`GamePlatformPortraitWidget`（通用肖像），角色档案卡片已由现有真实资源实现。
3. 技能/物品槽：`GamePlatformSlotWidget`（单格）；`GamePlatformSlotBarWidget`（通用快捷栏），项目`DivineBeastsAbilityBarPanel`接真实技能视图状态。
4. 小地图：`GamePlatformMinimapWidget`（UV标记、旋转、缩放、源版本）。
5. 队伍成员：`GamePlatformPartyRosterWidget`（最多32项成员、头像及生命展示），MOBA竞技状态由中层视图模型装配。
6. 倒计时：`GamePlatformCountdownWidget`（Event-driven显示时间），不在Widget中重建Timer。
7. 状态效果：`GamePlatformStatusEffectTrayWidget`（Buff/Debuff），只读图标、叠层和剩余时间。
8. 任务追踪：`GamePlatformQuestTrackerWidget`（最多16个目标），数据由QuestClient事实缓存适配。
9. 交互提示：`GamePlatformInteractionPromptWidget`（交互语义与输入提示），不直接执行权威交互。
10. 设置单项：`GamePlatformSettingRowWidget`（名称、显示值、不可用/待确认/错误态）；整体菜单`DivineBeastsSystemScreenBase`复用UI辅助功能，设备持久设置归Settings。
11. 悬浮提示：`GamePlatformTooltipWidget`（已本地化标题/描述与软图标）。
12. 其他现有跨游戏能力：对话框/短通知、伤害飘字/治疗数字、世界名称板/标记、反馈队列、异步加载页面、输入设备/安全区适配、焦点导航和可访问性。

## 三、蓝图与后续接线

- 原先已交付：`DBAUIPack_Core`中根布局、登录、角色创建/选择、英雄卡片、角色卡片共6个Widget蓝图。
- 新业务页面与通用组件：声明式设计规格已生成至`Saved/Monolith/GameUIComponentSpecs`，实际.uasset必须由Monolith MCP在锁定UE5.8编辑器中创建/编译/保存/回读。详见`DBAUIPack_Core/Docs/十大业务域Widget蓝图实施清单.md`。
- 不把“C++源码已写入”、“生成JSON规格”、“目录软引用存在”当成“蓝图可用”。业务接线还需单独验证Quest、Inventory、Setting、Arena和Social各自真实数据源。
- 审计项应至少包含：`UGamePlatformUIManagerSubsystem`层栈、父类加载、UI事件无Tick、每个Widget必需命名控件与焦点、真实蓝图资源数、移动布局和Dedicated Server剥离。
