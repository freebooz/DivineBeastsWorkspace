# Naming（命名规范）

固定前缀：

- `FXS_`：Niagara System（Niagara系统）
- `FXE_`：Niagara Emitter（Niagara发射器）
- `FXM_`：Niagara Module Script（Niagara模块脚本，项目扩展）
- `FXT_`：Niagara Effect Type（Niagara特效类型，项目扩展）
- `M_`：Material（材质）
- `MI_`：Material Instance（材质实例）
- `MF_`：Material Function（材质函数）
- `T_`：Texture（纹理）
- `SM_`：Static Mesh（静态网格）
- `DA_VFX_`：VFX Definition（VFX数据定义）
- `DA_VFXCAT_`：VFX Catalog（VFX目录）

平台资产作用域使用 `GPVFX`，项目资产使用 `DBA`。

示例：`FXS_DBA_Rat_ShadowStrike_Impact_Default`。
