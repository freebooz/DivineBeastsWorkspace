# Content 资产创建说明

本源码包**不会伪造 `.uasset` / `.umap` 文件**。这些二进制资产必须通过 UE5.8 编辑器创建。

建议创建：

- `/GamePlatformVFX/Development/Review/Maps/L_GPVFX_Review`
- `FXT_GPVFX_Critical`、`FXT_GPVFX_Combat`、`FXT_GPVFX_Status`、`FXT_GPVFX_Ambient`
- `M_GPVFX_Additive_Master`、`M_GPVFX_Translucent_Master`、`M_GPVFX_Ribbon_Master`
- `FXS_GPVFX_Instant_Generic`、`FXS_GPVFX_Attached_Generic`、`FXS_GPVFX_Beam_Generic`、`FXS_GPVFX_Area_Generic`

Niagara System / Emitter / Module Script 的具体制作参数见 `Docs/AssetAuthoring.md`。
