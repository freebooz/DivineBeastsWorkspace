# GamePlatformOnline 插件目录与当前实施边界

2026-09-21。以下列出本轮实际文件；不把计划中的模块、子系统或测试入口写成已完成实现。

```text
GamePlatformOnline/                                      # 平台在线插件唯一源码归属
├── README.md                                            # 接入签名、语义、阻断和验证状态
├── Docs/                                                # 插件内部中文交付说明
│   ├── 目录规划说明.md                                 # 当前真实文件清单
│   └── 安全断点记录.md                                 # 用户要求停工时的实现、测试和风险
├── Tests/                                               # 独立生产纯逻辑测试构建入口
│   └── CMakeLists.txt                                  # 不是额外 UE 宿主
├── Saved/                                               # 本轮原生测试临时产物，保留但不得发布
│   └── NativeTests/                                    # CMake、可执行文件及 CTest 日志
└── Source/                                              # 未来由正式 UE 模块编译的源码
    └── GamePlatformOnline/                              # 唯一计划运行模块，尚无构建装配
        ├── Public/                                      # 不含传输对象与令牌的 C++ 契约
        │   ├── Interfaces/                              # 唯一类型化服务门面
        │   │   └── IGamePlatformOnlineService.h         # 配置、六操作、取消与只读快照声明
        │   ├── Settings/                                # 显式非敏感配置值
        │   │   └── GamePlatformOnlineConfiguration.h   # 源地址、安全约束与请求预算
        │   └── Types/                                   # 公共输入、身份、状态与结果
        │       ├── GamePlatformOnlineRequests.h         # 生命周期选项、句柄、登录和更新输入
        │       ├── GamePlatformOnlineAuthentication.h   # 无秘密认证快照
        │       ├── GamePlatformOnlineProfile.h          # 当前玩家公共资料值
        │       ├── GamePlatformOnlineResult.h           # Core 结果复用与分操作终态
        │       └── GamePlatformOnlineDiagnostics.h      # 脱敏实例计数与状态
        └── Private/                                     # 内部实现及测试边界
            ├── Requests/                                # 生产纯逻辑，不依赖 UObject／HTTP
            │   ├── OnlineSession.h                     # 状态、传输边界和执行器声明
            │   └── OnlineSession.cpp                   # 请求、认证、刷新、退出与资料版本实现
            └── Tests/                                   # 测试源码，不进入正式认证传输
                ├── GamePlatformOnlinePublicContractTests.cpp # 待 UE 执行的默认值和签名测试
                └── OnlineSessionTests.cpp              # 仅原生测试宏编译的 8 组故障用例
```
