├── Source/                                                          # 唯一工程源码

│       ├── GamePlatformApplicationFlow.Build.cs                      # 模块构建和依赖规则
│       ├── Public/                                                  # 跨模块公开契约

新增、移动、重命名或删除文件时，同步维护本文、插件 README 和解决方案《总体目录规划说明》。改变契约时同步修改接口说明及相应用例。规范文档使用中文文件名，引擎、构建工具和脚本标识遵循技术命名约定。

本插件不需要资产、运行时默认配置或编辑器模块，因此不创建 Content、Editor 空壳。Config 仅包含 UE 打包文件过滤规则，不注册任何运行时配置或标签。真实登录、选角、世界准入等业务节点归各领域插件或项目组合根，不放入此处。

原生构建缓存和日志位于工作空间 `Saved/Validation/ApplicationFlow/Native/`，不属于插件源码。UE 报告使用调用方指定的全新目录，建议放在 `Saved/Validation/ApplicationFlow/UE/` 下；不得以历史报告替代本次验证。

UE 构建会自动生成插件 `Intermediate/`（UHT 与编译缓存）及成功时的 `Binaries/`（模块二进制），均为可再生成产物，不逐文件列入上方正式源码树。临时验证宿主位于工作空间 `Saved/Validation/ApplicationFlow/UEHost/`，通过 AdditionalPluginDirectories 引用本目录，不作为正式游戏主工程或第二套插件源码。
