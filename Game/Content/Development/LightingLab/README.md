# SSLM Lighting Lab 开发资源目录

本目录只用于UE5.8 Editor生成的独立艺术光照审核关卡及其纯开发资源。

- 资产挂载路径：`/Game/Development/LightingLab`。
- 正式新手村地图、正式天气定义、正式材质与运行时配置均不属于本目录。
- `.umap`、`.uasset`必须由家中开发PC的UE5.8编辑器/Monolith MCP真实创建、编译、保存和重载；禁止提交文本占位或改扩展名伪造资产。
- 本目录已加入`Game/Config/DefaultGame.ini`的`DirectoriesToNeverCook`及`Build/Game/ServerPresentationExclusions.json`的`AllServers`排除规则。实验资产不得进入正式Client或Dedicated Server产物。
- 本README仅用于在云端仓库保留目录与所有权说明，不代表任何UE原生关卡已生成。
