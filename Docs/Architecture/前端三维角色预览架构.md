# 神兽联盟前端三维角色预览架构

版本：1.0｜适用工程：DivineBeastsWorkspace（神兽联盟工作空间）

## 1. 定位

登录后的角色选择/创建三维预览属于 Client FrontEnd（客户端前端），不是 OpenWorld/Village/MainArena 正式游戏世界。

它没有 ServerRole（服务器角色）、World Assignment（世界分配）、Session Admission（会话准入）或 Dedicated Server（专用服务器）。ApplicationFlow（应用流程）仍是唯一业务流程状态机。

正式流程：

```text
Authentication
→ LoadProfile
→ LoadRoster
→ CharacterEntry
   ├─ Select Character
   └─ Create Character
      ↓
客户端本地三维预览
      ↓
ValidateSelection
→ ResolveExperience
→ RequestWorld
→ TransferWorld
→ WorldReady
→ InWorld
```

只有从 ResolveExperience 开始才进入正式世界分配链。

## 2. 三层架构

### 第一层：GamePlatformPresentation（游戏平台表现）

新增 `AGamePlatformCharacterPreviewStage（平台角色预览舞台）`。

职责：

- 持有 Preview Mesh（预览网格）、Camera（相机）与旋转/缩放控制；
- 接收已经加载完成的 SkeletalMesh / Material / AnimInstance；
- 不认识 DivineBeasts、十二生肖、Hero.Zodiac.*；
- `bReplicates=false`；
- 无 Tick；
- 无 GAS、Combat、Inventory、Equipment、AI；
- 不负责业务流程或后端请求。

### 第二层：MobaCommon（MOBA通用层）

不参与角色创建预览。角色创建不是 MOBA 规则。

### 第三层：DivineBeasts（神兽联盟项目层）

`UDivineBeastsCharacterPreviewSubsystem（神兽联盟角色预览子系统）`：

- 按需流送 `L_DBA_CharacterStudio`；
- 通过 `FDivineBeastsCharacterAppearanceCatalog` 复用 `DA_Appearance_Zodiac_*`；
- 异步加载 Mesh / Material / AnimInstance；
- 使用 RequestGeneration 拒绝迟到异步请求；
- 切换 Preview Stage 相机为本地 ViewTarget；
- 离开 CharacterEntry/CreateCharacter/ValidateSelection 时卸载预览场景。

`DivineBeastsUIClient（神兽联盟UI客户端）`：

- 根据 ApplicationFlow 的 ViewState 进入/退出预览；
- 默认预览已选角色、首个持久角色或首个可创建生肖；
- Blueprint 可调用 `PreviewCharacterHero / RotateCharacterPreview / SetCharacterPreviewCameraDistance`；
- 预览动作不提交角色选择，不修改 ApplicationFlow。

## 3. 内容包和地图

新增纯内容插件：

```text
Game/Plugins/DivineBeasts/ContentPacks/Presentation/DBAFrontEndPack/
├── DBAFrontEndPack.uplugin
├── README.md
└── Content/
    └── Maps/
        ├── L_DBA_FrontEnd.umap
        └── L_DBA_CharacterStudio.umap
```

### L_DBA_FrontEnd

客户端前端宿主地图。当前真实资产包含 `FrontEndCamera`。

它可承载 Login / CharacterSelect / CharacterCreate 等客户端 UI，但不拥有 ApplicationFlow 状态。

### L_DBA_CharacterStudio

按需流送的角色三维预览地图。当前真实资产包含：

- `CharacterPreviewStage`
- `PreviewKeyLight`
- `PreviewFillLight`
- `PreviewRimLight`

后续可以替换环境、美术灯光、地台、VFX 和音效，但不改变 Preview Stage 的通用接口。

## 4. 十二生肖复用关系

```text
HeroDefinitionId
    ↓
DA_Appearance_Zodiac_*
    ↓
Manny / Quinn（当前）
或正式生肖 SkeletalMesh（未来）
    ↓
AGamePlatformCharacterPreviewStage
```

当前开发期继续使用已生成的 12 个生肖 Appearance Profile 和颜色材质。

未来真实角色到位后只更新对应 `DBAHeroPack_*` 中的 Appearance Profile，不修改：

- L_DBA_FrontEnd；
- L_DBA_CharacterStudio；
- Preview Subsystem；
- UI 流程；
- HeroDefinitionId；
- CharacterId；
- 后端角色协议。

## 5. Client/Server隔离

```text
DivineBeastsArenaClient Target
    + DBAFrontEndPack

DivineBeastsArenaEditor Target
    + DBAFrontEndPack

DivineBeastsArenaServer Target
    × DBAFrontEndPack
```

DBAFrontEndPack 的插件描述同时限制为 Client / Editor。

Dedicated Server 不 Cook：

- L_DBA_FrontEnd；
- L_DBA_CharacterStudio；
- Preview Camera；
- Preview Lighting；
- 前端环境资源。

## 5.1 客户端启动地图策略

不把 `L_DBA_FrontEnd` 写入共享 `GameDefaultMap`。共享地图配置会同时影响 Dedicated Server，与“前端地图只存在客户端”的边界冲突。

当前 CharacterEntry/CreateCharacter/ValidateSelection 已通过 LocalPlayer 预览子系统动态流送 `L_DBA_CharacterStudio`，所以三维预览功能已经闭环。`L_DBA_FrontEnd` 保留为正式客户端宿主资产，等工程增加 Client-only 启动映射配置/启动器后再成为客户端启动图。

## 7. 性能和安全

- Preview Stage 无 Tick、无复制。
- CharacterStudio 只在角色前端流程需要时加载。
- Appearance/Profile 与视觉资源全部软加载。
- 英雄快速切换使用 RequestGeneration 防止旧异步回调覆盖新选择。
- 离开角色前端流程后取消未完成加载并请求卸载 CharacterStudio。
- 不为 12 个生肖创建 12 套 Actor/Pawn 类。
- 不通过三维预览对象保存后端角色权威状态。
