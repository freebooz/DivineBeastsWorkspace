# 角色模型变形修复记录

日期：2026-10-10。工作分支：main。范围：公共客户端角色蒙皮与开发待机；不调整协议、后端档案、服务器胶囊、出生点或世界地图。

## 根因与实际修改

Manny/Quinn简化网格均有89根骨骼，却绑定了68骨UE4 `SK_Mannequin_Skeleton`，缺少21根网格所需骨骼，包括spine_04/05、neck_02、手掌和第二扭转骨。Idle序列及动画蓝图同样使用旧骨架，旧参考姿势的spine_03骨长约13.41cm，真实Manny约7.24cm。仅放宽引擎兼容检查使模型可显示，不能解决蒙皮变形；IsCompatibleMesh(Mesh, false)在缺少子骨时可沿祖先查找匹配，且不核验父链；该宽松判断不能替代蒙皮所需骨骼的完整覆盖检查。

新增锁定UE5.8真实模板161骨骨架`/DBAContentPack_Common/Mannequins/UE5/Meshes/SK_Mannequin`，两个网格所需骨骼及父链全部匹配。模板源为引擎`Templates/TemplateResources/High/Characters/Content/Mannequins/Meshes/SK_Mannequin.uasset`，遵循项目的Epic模板使用许可；经Monolith加载、绑定项目网格、设置预览网格并保存。模板残留的`/Game/Characters/Mannequins`自引用和重定向来源通过引擎`rename_referencing_soft_object_paths`迁移，保存后AssetRegistry依赖仅含本内容包Manny/Quinn。旧UE4骨架和网格保留，不改已发布英雄或外观路径。

稳定AS/ABP_DBA_PreviewIdle绑定到正确骨架；通过引擎动画控制器按参考姿势重建4秒/30fps呼吸待机，没有根运动、骨骼缩放或身体平移。Skeleton平移重定向保留男女模型骨长。动画仍是开发原型，不代表正式生肖美术或完整行走动画。

AppearanceProfile新增已加载骨骼检查，预览Subsystem及世界AppearanceComponent在改网格前共用该门禁；检查动画蓝图目标骨架，保留异步代次、取消及租约所有权。允许骨架比简化网格多骨骼，拒绝网格所需骨骼缺失或父链不同，不依据身份标签/同指针放行。错误只记录资源及原因，不记录认证数据。

修复/生成脚本和实际IoStore门禁检查正确UE5依赖。中立编辑器制作入口同步Sequencer FK骨树，避免换Skeleton后仍用旧Rig写轨道；默认关闭的DeveloperTools必须在制作时显式启用，不进入客户端或专用服务器。
