# 新手村玩家可见性与移动动画修复记录

## 原因与范围

2026-10-10本次两个已登录客户端的实际日志均进入`127.0.0.1:17778`、`/DBAWorldPack_Village/Maps/L_Village_Start`，服务器实例相同。不能把“看不见对方”归因为两张关卡。原服务器准入桥只提交中立玩家上下文，没有把后端已选择角色接到角色可信初始化；客户端UI只给本机Pawn补外观，远端Actor缺少可公开复制的Hero身份。世界外观还使用纯预览Idle动画，没有速度驱动的行走接线。

## 实现与边界

- DBAServer私有桥用真实准入PlayerId读取既有PlayerData内部Profile/Roster，验证拥有关系、选中角色、Active状态、唯一身份和核心Hero Catalog；每个连接冻结服务端读取时的选择快照，不使用客户端Hero RPC或固定英雄回退。当前已领取准入投影不包含CharacterId，冻结的是已验证玩家的后端选择快照，不声称扩展了票据契约。
- 平台仍独占生成、控制和准备令牌。角色生成事实事件绑定可信持久角色与Hero、出生和Avatar代次；Hero公开复制，持久CharacterId仅Owner复制。独立IdentityChanged通知解决首次Hero到达时Ready仍为false而远端模型不加载的情况。
- 角色定义初始化受理不等于Ready。服务器消费准备令牌前额外查询真实角色Ready；桥消费加载失败/取消终态并设10秒截止，按当前真实连接释放准入。客户端在真实Ready事件后提交准备并开放输入。重生更换Pawn操作身份，旧Ready、超时及下一帧失败不能撤销后继。
- 外观世界挂接复用已有WorldSubsystem，没有新增平行角色生成器。Dedicated和非游戏/PIE世界拒绝纯表现装配，客户端租约、事件和旧加载回调按角色生命周期释放。
- 世界ABP直接向下继承平台`UGamePlatformLocomotionAnimInstance`，读取真实本地/复制速度和下落状态，使用0/150/500厘米每秒的Idle/Walk/Run混合及Fall分支。角色选择预览保持独立Idle。全部序列绑定161骨UE5 Skeleton、锁定根骨并关闭根运动，权威位移仍归CharacterMovement。
- 逻辑Hero定义显式进入Client/Server Cook；世界动画及依赖进入客户端IoStore门禁。服务器不得携带公共动画包、UI、前端或客户端模块，须另查实际发布制品。
