# 《神兽联盟》游戏端插件清单设计

> 更新日期：2026-09-27。
> 适用范围：`Game/Plugins（游戏插件目录）` 当前代码／机制插件。
> 本文以当前真实 `.uplugin（插件描述文件）`、模块和源码扫描为准，是插件名称、职责、模块端侧、实现状态和验证资料的主清单；目标目录规划、历史方案或文件存在不能替代真实实现与运行验收。

## 一、总体基线

当前代码／机制插件共 **46 个**：

- `GamePlatform（游戏平台层）`：39 个跨游戏通用插件。
- `MobaCommon（MOBA通用层）`：2 个插件，其中 `GamePlatformArena（游戏平台竞技场插件）` 保留 GamePlatform 稳定身份。
- `DivineBeasts（神兽联盟项目层）`：5 个项目代码插件。
- `ContentPacks（内容包）`：真实内容插件独立登记，当前不计入本表；现阶段真实 `.uasset（虚幻资产）` 与 `.umap（虚幻地图）` 仍为 0。

三层依赖方向：

```text
DivineBeasts（神兽联盟项目层）
        ↓
MobaCommon（MOBA通用层）
        ↓
GamePlatform（游戏平台层）
```

项目层允许直接依赖平台层。禁止平台层反向依赖 MOBA／项目层，禁止 MOBA 层依赖项目层。

### 状态说明

- **核心实装**：存在真实领域代码、接口／组件／Definition（定义）和测试基础，但不自动代表 G5 Production Ready（生产就绪）。
- **部分实装**：已有核心或状态内核，但端到端链路、公开服务或真实 UE 联调尚未闭合。
- **规格待实现**：已形成正式实现规格，但运行代码仍主要是模块壳。
- **预留／候选收敛**：当前无独立生产职责或只有模块壳，不得冒充已完成能力。
- **项目实装**：项目层已有真实项目规则或组合代码，仍需依赖真实资产／联机／Cook（烘焙）完成验收。

## 六、维护规则

1. 新增、删除、重命名、移动插件时，本清单必须在同一变更中更新。
2. 插件模块、端侧、职责或依赖变化时，必须同步更新本清单、插件 README、插件开发规范和总体目录规划。
3. “存在插件描述文件”不等于功能完成；状态必须以真实源码、测试、UE构建、联调、资产和 G0～G5 门禁为准。
4. 自动测试数量、Docs（文档）和 ManualReview（人工审核）仅表示验证材料存在，不表示 G4/G5 已通过。
5. `.uasset/.umap` 只能由 Unreal Editor（虚幻编辑器）真实创建，禁止文本占位。
6. 当前清单的下一次结构性更新，应在 Phase 1 Online/Session 闭环或插件退休决策实际落地后进行。
