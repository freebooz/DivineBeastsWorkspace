# SSLM 场景效果图全局策略 V1.0

> 项目：《神兽联盟：王者争霸》（DivineBeastsArena / DivineBeastsWorkspace，简称 SSLM）  
> 日期：2026-11-14｜状态：已确认的全局概念美术制作约束  
> **适用范围**：Village（新手村）、OpenWorld（开放世界）、MainArena（竞技地图），以及森林、山地、湖泊、溪流、村落、远古遗迹、洞穴、夜景、天气与后续所有场景概念效果图、原画、环境氛围图及其美术评审。  
> **权威边界**：本文是“场景效果图的创作与验收策略”，不另建第二套色彩/光照真源。颜色语义、屏幕参考HEX、曝光与光照制作应以[《SSLM 全局美术配色策略与色彩设计规范 V3.0》](SSLM全局美术配色策略与色彩设计规范_V3.0.md)为唯一权威；关卡设计、UE5.8实际资产和玩法可读性仍遵循现行专项规范。场景效果图不是已通过UE原生性能或地图验收的证据。

## 一、最高审美原则

1. **唯美第一，画面必须值得欣赏**：每个场景、每个主要观景角度都要像一幅经过艺术指导的东方幻想山水画。“一景一幅艺术画，一帧一幅视觉作品”作为全局审美目标；画面整体意境、柔和光影、视觉焦点、景物姿态、色彩韵律和构图协调度优先于素材数量、写实参数的简单堆砌。
2. **介于真实与艺术化之间**：地形起伏、岩层、植物根系、材质、水系和阴影具有自然可信的PBR逻辑；允许对树形、山形、季相色彩、景深层次和光束进行克制的艺术化优化，不追求机械的照片复制，也不使用夸张卡通材质、塑料反光和过度幻想荧光代替质感。
3. **自然、柔和、有方向的艺术光照**：主光与天光统一塑造形体，光束应有树冠遮挡或山谷开口作为来源；亮而不曝，暗而有细节，柔而不平，雾而不糊。允许晨曦暖金与阴影青绿、月光银蓝与微弱荧光形成冷暖对比，不得大面积刺眼直射、黑死阴影、高饱和色偏或强Bloom。
4. **美学不能牺牲玩法底线**：玩家可行走区域、交互/任务目标、角色和敌我轮廓、危险预警、技能范围必须清楚；美术效果图是艺术方向，不等于可无视游戏可读性、碰撞、导航、世界分区和GPU性能的正式场景。

## 二、构图与场景差异

- **每幅独立完整画作**：默认横向16:9、单区域、单主题、无拼版、无九宫格、无说明文字和UI水印（用户另有指定除外）。每幅都有一处清晰视觉主角，近景自然框景、中景主体、远景空气透视相互呼应；画面留白随地貌和镜头调整，不强制每张都有远山、雾、溪水或中央道路。
- **各游戏区域必须有专属特色**：森林以古树、藤蔓、蕨类和树冠光井为主；村落以自然木石民居、农业、生活场地为主；湖泊以水、倒影、岸线和山体为主；山地以高耸险峰、峭壁、林缘与天际线为主；远古遗迹以风化石环、生肖图腾、残柱和自然侵蚀为主；洞穴以层叠岩壁、湿度和有限光源为主；夜景可用月光和小面积生物荧光。
- **构图禁止模板化**：不得把不同场景重复画成“左边古树、中央弯曲泥路、远处雾光、左右蘑菇”的同一机位。根据地图功能选用俯视、仰视、横向跨越、环形空地、湖岸视角、树洞内部、悬崖边缘、森林中庭等不同镜头结构。
- **氛围真实而克制**：树冠遮天蔽日的森林允许浓雾与神秘气质，但远景雾应有层次，视线焦点保留；水、山、村落应按自身地理与气候建立不同光色，不将森林湿绿和荧光蘑菇复制到所有区域。

## 三、地表及道路配色（全局重点）

**正式要求：普通地面道路以自然土黄色泥土路为主，零星点缀少量不规则天然碎石；参照《王者荣耀》经典峡谷“土黄道路与鲜绿草地有清晰而柔和的视觉区分”的配色逻辑，但仅借鉴配色关系，不复制其具体贴图、地图和资产。**

以下沿用V3.0已有的**初始屏幕sRGB参考值**（不是第三方官方采样，也不能当作UE线性BaseColor直接赋值）：

| 地表语义 | 初始屏幕参考色 | 应用说明 |
| --- | --- | --- |
| 土黄浅色受光路面 | `#C5AD83` | 普通道路主要视觉基调 |
| 自然林间泥土道路 | `#B7A181` | 向周围草地、落叶和土壤自然过渡 |
| 标准泥土基色 | `#A88F6D` | 混合踩踏、湿干过渡及地貌变化 |
| 局部潮湿泥土 | `#79705C` | 雨后低洼、林下小面积湿痕，不能整路发黑 |
| 自然草地参考色 | `#6B9956` | 与道路建立适中的明度和色相对比 |
| 阳光草地参考色 | `#86AD62` | 阳光和嫩草过渡，避免荧光绿 |

**道路强制视觉规则：**
1. 普通路面平缓、宽窄自然、可通行；以土黄或暖黄褐土壤为连续主体，不默认铺装成连续石板、鹅卵石路、青灰砖路、白色玉石路或现代硬质道路。
2. 仅随机点缀少量小块、风化、不规则碎石，石块局部半埋于泥土，颜色与邻近岩层一致；不得在普通自然道路上形成完整步石链、均匀等距石砖或铺满画面的石面。远古遗址核心祭坛、已有石阶和特殊建筑广场可以在有场景逻辑时例外，需保持侵蚀感与自然过渡。
3. 用草边、落叶、苔藓、细沙、根系和极少碎石连接道路与地表；中远景纹理频率降低，避免杂乱密集小石子争夺注意力。
4. 潮湿泥土通过BaseColor、Roughness、Normal及小面积水迹共同表现，湿痕与积水依地势分布，不把道路全部涂黑、不将水洼铺满地面；雨林、湖边、溪谷可适度增加局部湿感。
5. 地面须在实际俯视/第三人称游戏相机下保持道路与草地可辨、宽度合理、英雄轮廓及技能可读，不用过强色调或高频细节代替艺术精致。

## 四、植被、遗迹与水体的艺术化尺度

- 森林使用体积雄伟、姿态优美且差异化的古榕、古槐及区域适宜乔木；林下大量自然群落式蕨类、藤蔓、湿润阔叶与苔藓。花草作为少量色彩点缀，巨型彩菌只用于确有奇幻生态设定的专属地点，不在每个林地机械出现。
- 新手村保持“中心山底湖—山腰民居和农耕平台—外围险峰—后山十二神兽洞府”的既定地图结构。桃、梨、樱花、银杏、黄山松、毛竹等按地形与季相成片种植；村落使用古朴自然木石结构，不用整齐现代建筑或大面积炫金琉璃宫殿替换生活区。
- 远古遗迹强调时间痕迹：破损石环、裂隙、植物侵蚀、石刻兽纹与风化表面。遗迹是少数特殊区域的视觉焦点，不能让所有区域都出现同一传送圆环或蓝色水晶。
- 水体重视水深、青碧透明度、岸线、水底、湿岩、倒影与瀑布雾化，绝不只靠整片高亮青蓝与夸张特效获得奇幻感。
- 对既定重点水体/山地/森林基准图，仅继承明确的形态、光照、植被或材质原则，不将单张概念图当作所有地区的地形模型。

## 五、效果图制作固定流程

1. **场景任务定位**：写明地图、区域名称、玩法功能、主视觉元素、时间天气及与相邻区域的地形关系。
2. **锁定母风格**：引用本文和V3.0色彩规范；选择与区域相符的已批准基准图，避免跨生境套用。
3. **先设计构图**：明确主焦点、镜头高度/视向、前中远景、路线和留白，且与同批场景有明显区别。
4. **制作效果图**：优先使用ChatGPT Image原创绘制；静态概念图与UE真实截图须清楚区分。每一场景默认单独一张16:9高清横幅，不拼版、不叠说明图，用户明确要求例外时另计。
5. **审美自检**：检查唯美感、形态可信度、柔和光影、主次对比、自然色彩、地面材质、植被疏密与空气透视；剔除炫光、强滤镜、僵硬重复、现代建筑以及不合场景的大片石路。
6. **游戏落地复核**：批准概念方向后，另用UE5.8在真实玩家相机/环境/画质下验证可通行路线、构图、遮挡、玩法信息和性能。未做真实原生验证时明确标记“概念效果图”。

## 六、AI效果图基础提示语（供后续所有任务复用）

> 《神兽联盟：王者争霸》（SSLM）东方奇幻艺术化写实场景，画面介于真实与艺术创作之间，以唯美为最高审美目标，使每一帧都像一幅精心设计的东方山水艺术画。自然可信的山石、水系、植被和PBR材质；柔和而有方向的暖金主光、自然天光与有层次的环境阴影，局部克制的体积光束，适当空气透视；清新、通透、丰富但不过饱和的色彩。普通道路以自然土黄色、暖黄褐泥土为主，边缘融入草地，少量不规则半埋石块，不铺满石板；参考《王者荣耀》自然地面与草地的色彩关系而不复制具体资产。根据本区域玩法指定一个与其他区域不同的视觉焦点、地貌结构和镜头构图。单幅独立16:9真实场景艺术画，细节自然、光影柔和、层次清晰，无拼版、无文字、无HUD、无现代建筑、无过曝、无过量荧光和重复模板式场景。

> **重要**：基础提示语必须结合具体地图主题替换局部光色、植物、岩石、天气和水体要求。例如幽暗森林与雪山不能统一套暖金晨光；普通村落不可无故出现科幻水晶或巨菌。

## 七、验收与变更说明

- **一眼审美**：是否具有令人愿意停留欣赏的画面美感；一眼可以认出该区域的专属视觉特色。
- **风格统一**：是否延续SSLM的东方奇幻艺术化写实及区域适宜的柔和光照，而非照片复制或卡通化。
- **地面检查**：普通道路是否以土黄色泥土为主体；石块是否只是少量点缀；草边过渡是否自然。
- **差异化检查**：多场景横向比较时，是否在地形、空间、构图、主景与生态上明显不同。
- **可落地检查**：概念图与真实UE5.8地图、引擎材质、性能及实际验收分开记录，不得误报已上线、已制作或已验收。
