# 《神兽联盟王者争霸》教程配图与技术示意图规范

**项目正式名称：**《神兽联盟王者争霸》  
**中文简称：**《神兽联盟》  
**项目代号：**SSLM  
**文档版本：**V1.0  
**日期：**2026-11-12  
**适用范围：**所有《神兽联盟》相关教程、操作指南、技术说明、培训材料和实施文档。

## 1. 目的

统一神兽联盟相关教程的图片来源、视觉风格、技术准确性和图片组织方式，确保配图原创、清晰、准确，并与项目《东方诗意自然主义·艺术化写实》美术方向保持一致。

## 2. 默认配图来源

1. 神兽联盟相关教程需要配图时，优先使用 ChatGPT Image 原创生成图片。
2. 不使用网络搜索图片替代教程所需的原创配图。
3. 原创图片应围绕当前教程主题制作，包括场景效果图、资产概念图、材质表现图、操作原理图和学习辅助示意图。
4. 同一教程的配图应保持统一的美术风格、色彩关系、光照方向和视觉质量。
5. 原创配图应服务于文字说明，不得只追求装饰效果而偏离当前知识点。

## 3. 真实软件界面与技术准确性

ChatGPT Image 适合制作原创效果图、概念图和解释性示意图，但不能将生成图当作真实软件界面或可执行节点图。

以下情况必须优先使用真实、可核验的资料：

- Unreal Engine、Gaea、SpeedTree、Substance 3D Painter、Blender 等软件的实际界面和版本差异。
- 精确的菜单位置、按钮名称、节点名称、参数值和连线关系。
- 需要证明实际工程已经创建、编译、保存或运行的操作结果。

真实界面截图应标注软件名称和版本；官方截图或外部参考图应明确标注来源及用途，不得冒充 ChatGPT Image 原创图。

对于节点连接、流程图和参数关系，优先使用真实软件截图或可校验的矢量/结构化图示。若使用 ChatGPT Image 绘制概念示意图，必须注明“原理示意，非真实软件截图”，并由实际软件或官方文档复核节点名称、参数和连接关系。

## 4. 图片组织规范

1. 一张图片应突出一个主要对象、一个操作步骤或一个技术主题。
2. 多个独立步骤原则上分别配图，不将多张独立效果图合并成拼版或拼贴图；用户明确要求总览拼版时除外。
3. 图片应具有足够分辨率，主体清晰，文字易读，避免无关装饰、重复元素和过度复杂背景。
4. 操作教程中的图片应与相邻步骤一一对应，不能使用与说明内容不匹配的泛化图片。
5. 图片中的文字、节点、参数和软件控件不得被当作真实操作依据，除非经过准确性核验。

## 5. 项目美术风格要求

涉及游戏场景、角色、植被、建筑、地形、水体和特效的教程配图，应遵循项目 V4.0 全局美术规范：

- 东方诗意自然主义·艺术化写实。
- 自然结构可信，形态经过艺术指导。
- 色彩自然、明快、协调，具有区域主题。
- 光照柔和，保留空间层次和材质细节。
- 水体遵循清澈翡翠青绿基准及对应水体专项。
- 角色、技能和战斗示意必须保持 MOBA 视觉可读性。

软件操作类配图以准确、清晰、易理解为第一优先级，不为追求美术风格而改变真实软件界面。

## 6. 外部图片使用例外

只有在确实需要展示真实官方界面、官方技术示例、用户指定的现有资源或不可替代的外部参考时，才使用外部图片。

使用时必须：

- 标明图片来源、软件/产品版本和使用目的。
- 区分官方截图、用户提供图片、外部参考图片和 ChatGPT Image 原创图片。
- 不将外部图片描述为原创生成。
- 不以外部图片替代本应制作的教程原创插图。

## 7. 教程交付检查

每份神兽联盟教程发布前，检查：

1. 是否优先采用 ChatGPT Image 原创配图。
2. 是否误用网络搜索图片替代原创教程插图。
3. 图片是否与当前步骤和说明严格对应。
4. 真实软件界面是否来自对应软件版本。
5. 节点名称、参数和连线是否经过技术核验。
6. 多张图片是否按步骤独立组织。
7. 图片是否遵循项目 V4.0 美术规范。
8. 外部图片是否明确标注来源和用途。

本规范适用于后续所有神兽联盟教程和技术说明。
