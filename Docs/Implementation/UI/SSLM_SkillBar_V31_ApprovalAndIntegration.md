## 三、现有系统不可破坏的约束

当前 UDivineBeastsAbilityBarPanel（项目技能条面板）仅具有5种真实技能绑定：普通攻击、被动、两个主动技能、终极技能。8个外观槽位不等于已有8项GAS（游戏能力系统）授权，新增3格必须禁用并留空，直到真实技能配置及视图模型订阅完成。不得伪造技能数据、固定快捷键、独立于服务器授权发起技能命令。

原有ViewModel（视图模型）的只读授权、冷却、图标异步加载、角色更换及按键映射必须保留，不得以Tick重复访问ASC（能力系统组件）。气势值0—100与生命/能量蓝条完全独立。

## 四、人工审核和接入顺序

1. 下载本对话交付的 SSLM_SkillBar_V31_人工审核_待导入资源包.zip，解压并打开 SSLM_V31_人工审核.html（离线逐图审核页面）。
2. 人工逐项复核13张独立RGBA纹理的透明度、边缘、固定尺寸、分层关系，以及施法和气势0/50/100显示。
3. 人工导出 SSLM_V31_ApprovalRecord.json（具名审核结果），全部13项通过且 allow_unreal_import 为 true 后才允许导入审核目录。
4. 将整个解压后的 SSLM_SkillBar_V31_HumanReview 目录放入 DBAUIPack_Core/SourceArt/UI/SkillBarReview，或设置环境变量 SSLM_SKILLBAR_REVIEW_DIR 指向该目录。
5. 在UE5.8 Editor运行 Tools/Unreal/UI/ImportSSLMSkillBarV31.py（受控纹理导入脚本），只导入到 /DBAUIPack_Core/UI/Textures/SkillBarReview（项目审核贴图路径），不改正式WBP。
6. 在插件开发演示入口制作隔离的 WBP_DBA_UI_SkillBarReview（技能栏审核蓝图），显示8+3槽位、施法状态和气势0/50/100；留存截图，进行蓝图编译保存、冷重载与移动/PC显示检查。
7. 在明确的第二次人工批准后，备份既有 WBP_DBA_UI_AbilityBar（正式技能栏），仅修改视觉层和必要的只读8槽视图映射，不改GAS授权，再进行运行回归与合并。
