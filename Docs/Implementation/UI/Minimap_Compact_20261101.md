# SSLM紧凑圆形小地图实施计划与记录

> 执行方式：使用writing-plans和executing-plans，在当前正式UE工程中串行实施；用户已要求计划后直接执行。

**目标：** 将已批准的窄金属圆框小地图接入现有新手村HUD，保留真实定位、朝向与缩放合同。

**分层：** GamePlatformUI继续拥有中立快照/组件；DivineBeastsVillageMinimapWidget继续负责项目地图投影和生命周期；DBAUIPack_Core拥有项目美术、UMG和底图。无新插件、播放器、世界复制或业务权威。

## 基准和证据

- 正式工程：`Game/DivineBeastsArena.uproject`；UE5.8；当前编辑器PID65604、Monolith9317；正式新手村已打开，初检脏地图/内容均为空。
- 当前分支main有其他既存源码和VFX修改，保持原样；本轮不提交主分支。
- 已批准效果图：`Saved/ArtReview/Minimap20261101/SSLM_Minimap_Compact_20261101.png`。
- 尺寸基准：地图198×198逻辑单位；圆框外径206，径向4；标题与三按钮区域控制在约232×236，右上安全区内。实际物理像素随项目DPI曲线变化，不整页缩放字体。
- 原生RED：MapCanvas184×184，旧NatureMinimapFrame270×270；当前底图RGB均为75～91的灰值且源Alpha为0，不能用作地形视觉验收。
- 不将AI设计图中的村庄绘画/虚拟图标导入为真实底图。仅使用真实UE场景捕获和真实数据标记。

- [ ] P1：备份现有小地图、根布局、底图及实际修改的资源，记录哈希；核对原生Widget树和实际HUD锚点。

## 复用与性能

底图为离线静态纹理，不增加每帧SceneCapture。沿用现有Pawn移动通知、异步加载、版本和取消处理，不新增Tick或常驻计时器；按钮仅改变本地1/2/4倍显示。金属圈与按钮以小面积UI材质表现，参数可编辑，不烘焙宽边装饰。没有实测不宣称FPS/GPU毫秒改善。

本轮以已实现的玩家位置/朝向和缩放显示为功能基线；队友、怪物、NPC与任务只显示有真实事件来源的内容，不在底图绘制虚假动态标记。本次视觉改造不扩大成任务/视野/组队系统开发。
