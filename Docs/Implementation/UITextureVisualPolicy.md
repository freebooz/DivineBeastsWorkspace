本文件同步用户全局策略文件中的2026-10-11视觉标准，供项目克隆、人工制作和审核查阅。原稿色彩链路细则见[UIColorPipeline](UIColorPipeline.md)。

**2026-10-18新增全局色彩依赖**：配色语义以[SSLM全局美术配色规范V3.0](../Art/SSLM全局美术配色策略与色彩设计规范_V3.0.md)为唯一主标准；本文件继续负责已确认UI原稿的RGB/Alpha保护、质感、像素和导入/显示链路。玄墨青/碧玉/鎏金用于UI品牌而非全场景滤镜，生命绿/能量蓝/气势暖金/施法亮玉青的实际资源变更必须人工验收，不能直接覆盖现有原稿。

## 用户界面纹理全局视觉策略（2026-10-11）

来源：用户于2026-10-11明确指定。适用于SSLM全部用户界面纹理，以及后续未由用户明确另定视觉风格的项目界面纹理；后续用户明确指令优先。

### 统一视觉目标

采用高品质3A游戏电影级渲染风格，表面光洁温润、材质精细抛光、线条优美流畅、光照柔和真实、高光宽阔连续。采用低对比度的自然微观纹理，严格控制高频细节与局部锐化强度，杜绝任何颗粒感、砂砾感、过度纹理化、碎片化高光和人工锐化痕迹。整体呈现纯净、细腻、通透、优雅且富有高级质感的视觉效果。

采用自然、藤蔓、树叶、碧绿、玉石、原始、远古等元素风格。远古与原始体现文化形制、自然生命和图腾意象，不以粗糙风化、砂砾、裂屑、斑驳噪点或粗糙铸造表面表达高级质感。本要求取代此前以粗糙、高频雕刻细节或局部锐化增强界面质感的制作取向。

### 纹理制作与验收约束

1. 适用范围包含LOGO及品牌装饰、登录与封面、菜单按钮、通用面板、头像框、技能栏、小地图外框、任务、背包、设置、对话框及其正常、悬停、按下、选中、禁用状态；新制与重制纹理必须统一执行本标准。
2. 玉石表现为温润、细腻、通透且精细抛光；藤蔓、树叶及边框线条优美、流畅、完整。自然纹理采用低对比度、低视觉密度的微观变化，禁止堆积细碎雕刻、噪点和高频纹理。
3. 光照柔和真实，高光宽阔、连续，明暗过渡平滑。禁止碎片化高光、密集闪点、硬切亮斑、过曝白边、锐化光晕及明显人工锐化痕迹。
4. 禁止胶片颗粒、砂砾噪声、粗糙磨砂、过度纹理化及以噪声掩盖低质量资源；不要将“电影级”“原始”“远古”理解为添加颗粒、脏污或增强局部锐化。
5. 用户指定原稿复用时保留原稿RGB；新制纹理按本标准制作。彩色图与线性Alpha遮罩分开管理，采用正确sRGB、无损界面压缩、白色乘色及明确的透明度合同，防止重复Gamma编码或额外滤色。不能通过调亮、调暗、色调滤镜或锐化补偿错误的导入与显示链路。
6. 同时检查原尺寸像素和游戏实际显示尺寸：质感须保持纯净细腻，缩小后不得出现颗粒聚集、细节破碎、锯齿和闪烁。文字、输入和交互控件保持既定固定字号与大小，不通过整页缩放掩盖纹理问题；背景和面板可按其原生等比或九宫格规则适配。
7. SSLM资产继续遵守三层、插件化及Monolith MCP规则：通用机制归GamePlatformUI，项目公共视觉归DBAUIPack_Core，项目适配归DBAClient；真实界面资产须通过Monolith创建、修改、编译、保存、重载并留证。源图与预览不代替真实客户端渲染和人工视觉验收。

## SSLM导入执行门禁

后续每次导入或重导入项目界面原稿，必须执行[颜色链路规范](UIColorPipeline.md)中的导入后阻断审计：通过Monolith调用`Tests/Assets/AuditUIColorImportedAssetsMonolith.py`，包括已存在的纹理。动作自身的失败字段必须阻断后续交付，不得只看工具传输层是否报错；无损设置、正确sRGB及源图哈希通过后，仍须完成材质采样器、保存重载、真实GPU及新版客户端验证。禁止调用Monolith 0.23.0的Widget预览PNG路径用于界面预览、用户展示或验收，禁止调暗/锐化原稿补偿其额外Gamma编码。采用原生截图或线性浮点RHI回读且单次编码的PNG；前端发布须通过TestUIColorRHI的当前资源指纹门禁。任一环节未执行或失败必须明确标为未验收。
