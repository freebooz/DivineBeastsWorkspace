1. 鼠标在 UI 上释放、双键与旅行交错，不得执行旧世界目标命令。
2. 视图模型换 Pawn/失活必须解绑真实来源，异步资源旧回调不得复活页面。
3. 状态时间未知、永久、刷新和取消不能相互冒充。
4. 未授权的目标属性、无公共组队后端、无当前地图资源必须保持明确不可用。
5. 不能把源代码实现、静态通过、Editor 构建、资产保存或单机运行混为同一验收结论。
