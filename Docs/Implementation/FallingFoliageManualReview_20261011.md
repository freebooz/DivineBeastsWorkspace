## 二、角色选择与角色创建

1. 启动正式Client，使用授权开发测试账号完成真实登录，不将密码写入日志。
2. 进入CharacterEntry（选择或创建角色入口），确认角色三维预览工作室`L_DBA_CharacterStudio`成功流送。
3. [ ] 默认显示Peach（桃花花瓣）风格且只启动一组持续环境表现；
4. [ ] 近/中/远景花瓣数量恰当，角色轮廓、面部与角色名操作控件无遮挡；
5. [ ] 花瓣完整经历空中飘落→落地静置→贴地滑动/翻滚→阵风二次扬起→重新飘落；
6. [ ] 场景采用Landscape（地形）时，锚点高度Z=-1cm附近无明显花瓣穿地/漂浮；若局部坡面不适配，标记失败并改用地形采样；
7. [ ] 从角色选择进入角色创建、返回选择和快速切换生肖时，粒子不重复叠加、不丢失；
8. [ ] 使用已有`SetPreviewFoliageStyle（切换预览飘落风格）`顺序切换Maple（枫叶）、Bamboo（竹叶）、Ginkgo（银杏）和Peach（桃花），检查四种形状、颜色、运动差异；
9. [ ] 关闭/返回登录并立即重进预览工作室，原粒子正确取消，新请求使用正确的场景代次；
10. [ ] 切换游戏世界/退出客户端无残留组件、重复Definition租约或旧异步回调恢复。

## 三、自然风场状态

- [ ] 无风：花瓣缓慢落下，地面大多数粒子静止；
- [ ] 微风：贴地滑行及轻微翻面可见，动态自然、不整齐一致；
- [ ] 阵风：局部花瓣被卷起，旋转与二次飘落连贯；
- [ ] 叶片质量差异：枫叶相对翻滚、竹叶方向性更强、桃花更轻盈；
- [ ] 在高低档画质下环境级特效能降级，不能抢占战斗关键VFX预算。
