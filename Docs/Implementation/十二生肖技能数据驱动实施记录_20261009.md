## 三层架构与真实归属

**GamePlatform（游戏平台通用层）**：保持原有 GamePlatformData（Definition ID/租约）、GamePlatformAbilitySystem（GAS/技能集）、GamePlatformCombat（权威伤害）、GamePlatformUI（通用槽位）不复制机制。无生肖类型泄漏到平台层。

**MobaCommon（MOBA 可选层）**：保持原有竞技通用能力和 MobaPresentation（MOBA表现语义），此轮未新增具体生肖技能依赖；Village/OpenWorld（新手村/常驻世界）不被迫启用 MOBA。

**DivineBeasts（神兽联盟项目层）**：
- DBAGameplay（双端项目玩法）：新增 DivineBeastsAbilitiesRuntime（生肖技能运行模块），包含 AbilityDefinition（技能逻辑定义）、AbilityBalanceRow（技能每级数值结构）、ConfiguredGameplayAbility（数据驱动技能基类）、AbilityLoadoutComponent（技能授权与复制）、GameplayCharacter（组合唯一 ASC、身份、战斗、技能装配组件）。旧 DivineBeastsCharactersRuntime（项目角色模块）只增加 DefaultAbilitySetId（默认技能集逻辑引用）。
- DBAArena（可选竞技）：DivineBeastsArenaServer 的 SpawnPlayer（竞技出生路径）改为创建项目可玩角色类，现有角色身份和竞技流程保持原位。
- DBAClient（项目客户端）：新增 AbilityUIProfile（技能图标/名称表现定义）、AbilityBarViewModel（只读技能槽投影），原 AbilityBarPanel（技能栏面板）在 Widget 构造及换 Pawn 时绑定、关闭时解绑。
- DBAServer（公共服务器）：原有控制面职责不变。本轮没有发现通用世界三个服务角色的真实 Pawn 接线可以安全统一替换，OpenWorld/Village 的出生组合尚需后续实际集成；不额外创建 Server-only（仅服务器）技能管理器。
- DBAHeroPack_*（英雄内容包）和 DBAUIPack_Core（公共 UI 内容包）：保留原目录及真实资产；未新增空内容插件或伪 .uasset。
