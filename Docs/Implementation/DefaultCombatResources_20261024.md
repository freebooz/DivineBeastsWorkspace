# 出生属性与默认施法能量

用户要求：玩家及怪物出生生命100、能量100，默认每秒恢复能量5，法术默认消耗25。生命与能量上限沿用现有100，气势独立；普通攻击与被动不新增默认能量消耗。

现状：平台属性构造已为100/100生命和100/100能量，重生会补满能量；怪物生成仍传入75生命。开发法术及占位法术明确返回无成本GE，技能授予校验仅允许Momentum修改，尚无能量恢复链。
