## 二、鸟种和数量设置

选择场景中的鸟群Actor，选中其 `BirdFlock` 场景组件。在 `SpeciesId（鸟种）` 下拉中选择 `Seagull（海鸥）`、`Swallow（燕子）` 或 `Eagle（雄鹰）`；`BirdCount（数量）` 设置0–512。`FlockId（鸟群身份）` 保持同一本地玩家范围内唯一，避免多个场景Actor互相替换请求。

编辑普通关卡后保存，再进入PIE观察。运行时也可调用组件 `ApplyBirdFlock（应用当前设置）` 和 `StopBirdFlock（停止本群）`；后台加载失败或非法输入会明确拒绝，不用假资源遮盖错误。0代表停止，不是把鸟缩小至不可见。

三种WorldDefinition（物种数据资产）的默认数量为海鸥32、燕子72、雄鹰5。需要调整路径、半径、高度、速度或风扰动时，在各自 `DA_DBA_VFX_BirdFlock_*` 的 `DefaultParameters（默认参数）` 中修改已列入白名单的字段；不要使用历史ISM原型预设替代正式WorldDefinition。

### 2026-10-15 自然非圆路线续修（独立于上一轮间距签收）

用户反馈鸟群持续绕圆。实际Village默认入口只覆盖数量，海鸥和鹰仍使用Mode0；旧HLSL的Mode0为圆，Mode1为椭圆，因此不能只换另一默认模式就声称解决。此次保留原模块/系统身份、八个模块输入、稳定UniqueID、32/24/5正式数量与240/180/380cm最小中心距，改为左右交替的S型与伸长八字掠行。Mode0为宽缓滑翔，Mode1为长距离S型掠过，Mode2为较紧凑八字；项目海鸥默认改1、燕子保留2、鹰保留0，整数枚举身份不重命名。

每层横向公式为`(A*r*sin(a), B*r*sin(2a))`，`r=0.9*Radius`。三模式的`A/B/距离保守下界c/公共起伏幅度cm`分别为`1.7/0.8/1.10/120`、`1.8/0.55/1.02/72`、`1.6/0.65/1.015/60`。公共缓慢漂移和高度变化不会改变粒子对距离；不再让整个群落描一条固定圆周。速度字段包含所有轨迹、风和高度项的解析导数，名义FlightSpeed控制厘米/秒运动尺度，允许转弯平滑变速。没有逐鸟CPU扫描、玩法轮询或新的播放器。

对同层半相位内的两个个体，令相位差为δ、中点为m：距离平方除以`r²*sin²δ`，下界为`A²*cos²(m)+4B²*cos²(2m)`，最小值为`A²/2-A⁴/(64B²)`。上述c均低于其平方根。容量按`floor(π/asin(spacing/(c*r)))`选择；单层尺寸不足时容量为1。不同层的Z差始终至少spacing。所有个体共用时钟角速度、漂移和起伏，因此这一几何约束覆盖连续模拟时间；纯测试为CPU双精度执行HLSL源码，不等于GPU浮点、真实绑定或整生命周期实测。

原系统和发射器固定Bounds维持`(-24000,-16000,-1000)..(24000,16000,12000)cm`。正式默认数量的中心Z全时包络为：海鸥32只658..1042、燕子24只420..720、鹰5只1090..1710cm；同一默认Radius/Height下512只分别为297.5..6441.5、199.5..5359.5、490..10610cm。三物种的三模式、正式/资产默认/128/512，以及Radius=10000、Height=10000、Wind=2000组合均须审计XYZ完整包络，额外计入真实网格包围球、Bounds原点偏移、Renderer Scale/Pivot、最大粒子缩放1.11、振翅WPO及单边7.5cm余量。实际余量每次由编辑器读取，不复用历史尺寸冒充当前资产。

字段单独范围合法不代表任意组合都受支持：例如Radius=200、Count=512、Eagle spacing=380会导致高度层超出原Bounds；spacing=1000与最大数量/高度也可能超界。这些组合必须重新作者审计或明确拒绝，不扩大所有系统Bounds掩盖问题。正式运行入口当前只覆盖Count/已支持Mode；通用VFX自定义Radius/Height/Spacing的调用方不能把字段Schema范围当成已批准的任意组合。现有运行时Schema未新增跨字段几何判定，本轮新增的是制作/保存前的明确拒绝门禁。

另有实际作者合同问题：旧系统同时保存Float与Int类型的同名FlightMode/FlockSeed，按名设置首项会让Definition整数覆盖与HLSL读取不一致。作者保持现有整数Schema与模块float接口，使用引擎`MakeFloatFromInt`动态输入桥接；删除前必须先核对命中的是多余Float，禁止误删整数或修改稳定Schema。保存和冷重载门禁检查唯一整数类型、两个真实转换节点、八个语义输入、InputMap暴露/非孤立和图无回环，不能只相信编译缓存。
