# 飞鸟审查与蝴蝶、鱼群实施计划
> 执行：实施计划、系统排错、独立代码审查；用户已授权连续实现。
> 工程：DivineBeastsWorkspace；UE5.8；GamePlatform平台层→可选MobaCommon→DivineBeasts项目层。
> 设计依据：本会话已评审的方案、现行AGENTS/插件开发规范/BirdFlock.md。执行中main由074b260更新到bd106b3，以每次实际修订保护其他工作。

## 目标与架构
修复正式飞鸟确认缺陷；实现蝴蝶和鱼各至少一种真实模型、PBR材质、Niagara、WorldDefinition、场景蓝图及行为验证。
保持单一GamePlatformVFX（Client/Editor模块）、Presentation中立入口、Data唯一资源租约和第三层物种内容。
本轮采用受控群落CPU状态求解＋Niagara批量网格表现，落实完整花点占位、受惊、局部鱼群邻域与水域约束，无逐个Actor或GPU回读。GPU邻域计算属于可替换优化路径，不宣称本轮已实现。
纯环境表现不复制个体、不决定玩法、不进入Dedicated Server。资产必须由引擎生成，所有新增一方代码完整中文说明，不新建空插件/第二播放器/资源加载器。
不提交推送、不发布，不覆盖无关修改。

## 重点风险
场景标识冲突、卸载误停、同世界上下文重放；异步失败/重入/迟到回调；无效/非有限参数；花点容量与释放；水域边界/障碍；裁剪隐形计算；重复Burst；池复用和退出清理。
