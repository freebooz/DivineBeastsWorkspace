## 正式审批与实施门禁

- 正式技能身份：当前 **0/60 已批准**；开发编号不可直接转为发布编号。
- 成本/冷却/伤害：须由服务器 GAS（Gameplay Ability System，玩法能力系统）和 GamePlatformCombat（平台战斗）按真实数据表执行，不允许客户端自行决定。
- 资产分层：GamePlatform（平台底层）保留通用技能/战斗/UI机制；MobaCommon（MOBA通用层）保留中立竞技语义；DBAGameplay（神兽联盟玩法层）拥有技能定义/数值；DBAClient及HeroPack（项目客户端与英雄内容包）拥有图标/VFX/SFX。
- 端侧门禁：技能开发目录 `/Game/Development/DivineBeasts/Abilities`（开发资产）不得随正式 Client/Server（客户端/服务器）Cook（资源烘焙）。
- 发布门禁：必须完成编辑器/客户端/服务器构建、真实技能集授权、双客户端Dedicated Server（专用服务器）联调、碰撞伤害/气势冷却用例、图标/蓝图绑定及正式Cook/Stage，且跨世界/重生/断线重连无旧技能残留。

**当前结果**：仅完成“可供人工审批的数据草案”和已分离的开发UE资产，不代表 P0—P7 已全部交付。
