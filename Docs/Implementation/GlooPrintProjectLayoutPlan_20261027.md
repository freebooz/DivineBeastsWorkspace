# GlooPrint项目蓝图批处理计划

用户要求使用GlooPrint重新排列项目全部蓝图。本次复用已安装GlooPrint 1.1.0的测量、布局及事务提交代码；默认间距和布局比例保持插件现有设置。该操作只面向编辑器资产，不进行客户端或服务器构建、Cook或部署。

- [ ] 在GlooPrint编辑器模块添加薄批处理入口，动态枚举/Game和本工程内容插件的Blueprint及地图内嵌LevelScriptBlueprint。
- [ ] 先输出逐资产、逐图清单和不支持原因；复制原始资产及侧车文件到本工程Saved备份目录，保存原始哈希。
- [ ] 分资产处理：使用GlooPrint原生算法；比较节点身份、连接、引脚值与非布局节点属性；仅保存发生变化且编译通过的资产。
- [ ] 原生保存后独立UE进程重新加载，比较图语义指纹与保存前布局；失败项目单独保留原文件和原因，不通过降低校验伪造成功。
- [ ] 恢复人工编辑窗口，交付准确的资产、图、节点变化及未处理清单。

特殊情况：空图或单节点无须移动；动画姿态图、状态机图及其他GlooPrint不支持的Schema保留并登记。源码桥接只存在第三方Editor模块内部，不创建第二套排列算法或运行框架。原有未提交内容以本次开始时的真实文件为备份基线，不使用Git重置覆盖。
