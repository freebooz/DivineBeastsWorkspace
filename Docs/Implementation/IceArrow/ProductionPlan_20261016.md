# SSLM 寒冰箭 A 方案原生制作与验收计划（2026-10-16）

> 执行方式：在当前正式工程中通过 Monolith MCP 逐层实施。以用户本轮 P0—P7 制作要求为验收依据；不另建工程、不改变技能权威。

**目标：** 将已选定的 A「玄霜棱矢」落实为可运行、可观察、可分级的立体寒冰箭，并保留真实编译、逐层截图、连续动画与性能证据。

**架构：** 项目资源属于 `DBAPresentationPack_Core`，中立请求继续经项目 Catalog/Definition 进入唯一 `GamePlatformVFX` 执行器。材质与 Niagara 负责纯表现；服务器/GAS 保持既有命中、伤害、冷却和技能时序。

**工具：** UE5.8.0、锁定 Monolith 0.23.0、项目既有资源与验证入口。实际接口以本次运行时 discover/schema 为准。

**设计依据：** 用户本轮选择 A；第一轮原图位于本机图像生成记录。当前尚无第二轮动态分镜图、第三轮独立素材设计图；以下时间分解是制作方案，不冒称已经存在的确认稿。

## 视觉合同与阶段时间

- 冰晶主体为有厚度的尖锐棱矢，前端沿弹道方向；主体切面、内部细长蓝白核心、青蓝边缘能量、渐细尾迹、稀疏碎屑保持主次。
- 暗蓝切面不能被大面积辉光覆盖；避免把碎屑堆积、半透明雾墙或白色光团当成细节。
- 施法由真实 Cast 窗口驱动。先核对角色动画长度、既有脚底锚点与局部坐标，再安排凝聚与释放；不为概念图擅自改变服务器前摇。
- 飞行持续时间由真实投射物生命周期控制，视觉只跟随位置/朝向；尾迹随历史路径逐渐衰减，不在停止后继续发射。
- 命中以接触事件为零点，拟定 0—0.08 秒主闪光、0.03—0.30 秒晶体外推和薄环、0.10—0.85 秒碎晶减速与冰雾消散。最终数值须依据真实渲染调整，不是性能实测值。
- 冲击波仅为局部反馈，不新增范围伤害、冻结或击飞。残霜沿用真实静态地面查询。

## 重点失败路径

1. GPU 模拟预览黑屏：检查渲染世界、实际帧推进、Bounds、粒子数、材质与曝光，不把文件生成当可见性通过。
2. 旧脚底锚点与手部概念差异：检查真实角色局部坐标，保留已有地面法阵不悬空；不能只移动图中的发光中心而忽略实际挂点。
3. 飞行取消/命中清理：不遗留轨迹、循环发射或旧世界回调；预测确认不重复命中。
4. 低画质/并发降级：优先减少可选雾和碎屑，保留方向、主体和接触点；不得全局降低平台预算影响 OpenWorld/Village。
5. 资源身份与覆盖：保留稳定 Definition ID，未通过截图/编译的候选不能替换已验收效果；禁止手写 .uasset/.umap。
