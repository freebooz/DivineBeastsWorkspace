# 角色死亡通用消散实施计划

**目标：** 全部具有真实死亡状态的玩家和怪物，在死亡动画后通过材质消散退场；可复用于其他游戏和后续可死亡NPC。当前友好NPC没有死亡权威，不新增攻击资格。

**架构：** GamePlatformVFXClient提供不依赖Combat或项目类型的通用Mesh消散组件；DivineBeastsPresentationClient向下派生，只读Combat死亡/化身通知并装配。MOBA层目前无需新增类型。已有平台/项目溶解材质函数及内容所有权保持原位，不创建新插件、播放器或资产管理器。

**技术：** UE5.8、事件通知、动态材质、材质Time及一次性结束计时器、Monolith原生作者与重载。仅客户端消费表现，不修改权威伤害、碰撞、4秒狼尸清理、5秒玩家重生或竞技淘汰规则。

## 方案与取舍

采用现有角色材质接入共享溶解函数，保留基础色、法线、粗糙度和现有遮罩；短暂保留死亡动画后，噪声边界带克制能量亮边，最后隐藏各Mesh。相比用半透明整体淡出，Masked材质可保持实体质感并限制透明过绘。基础版不生成独立Niagara系统；可选粒子增强继续走现有Presentation→VFX执行链。

默认延迟0.65秒、消散1.5秒，总计2.15秒，均可在组件参数中配置。渲染材质使用Time插值；不以Tick或周期Timer读取死亡/写材质参数。材质缺少合同则登记并在截止隐藏作为回退，不宣称该材质完成渐变消散。

## 生命周期与边界

- 死亡事实只读现有Combat复制和观察通知，不依赖可丢包的短反馈，不新增复制字段。
- 同Actor/化身重复事件不重播、不延后截止。首次绑定已经死亡的实体直接保持隐藏，避免迟到加入重播尸体退场。
- 同Pawn重生、换代、异步外观装配、EndPlay和World退出恢复或释放自身材质/可见性及计时器；外部已替换材质不得被旧回调覆盖。
- 活着时不创建MID；消散中只处理所属角色及其子Actor的Mesh，不修改游戏碰撞、Actor权威生命周期或UI。
- 纯客户端组件/材质不能进入Dedicated Server。现有内容包和Data加载链承担资源所有权，组件不加载资产。

- [ ] 在GamePlatformVFXClient增加Mesh消散组件，在DivineBeastsPresentationClient增加只读死亡适配；接入现有角色生成和三类外观完成事件。

- [ ] 编译受影响Editor/Client目标，运行原生生命周期与资产合同回归；保存重载并留存主体消散原生截图/视频。
- [ ] 执行三层/命名/服务器隔离门禁，登记Cook、部署、性能和人工验收的真实完成边界。

## 审核重点

多材质及附件一致退场；透明/原有Masked材质保持原遮罩；死亡中异步模型到达不能重新显形；新化身不能继承旧MID；远端初始死亡和活体重复通知；材质动画不改变Gameplay；NPC无死亡状态时不伪造触发。尚未实现/运行的步骤不写成通过。

当前工作空间有其他任务修改，保留其文件与编辑器状态。新增文件在总体目录说明同步登记；用户要求的旧编译产物清理仅针对本次受影响、可再生的目标，不删除项目与资产。
