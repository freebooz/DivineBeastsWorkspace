# 通用材质函数库命名与质量门禁

## 一、命名

- `MF_GP_*`（平台材质函数）、`ML_GP_*`（平台材质层）、`MLB_GP_*`（平台材质层混合）、`M_GP_*`（平台材质母版）、`MI_GP_*`（平台材质实例）、`MPC_GP_*`（平台材质参数集合）：保留现有已发布身份，不为重排目录重命名。
- `MI_DBA_*`（项目材质实例）和`DA_DBA_*`（项目定义资产）只存在于实际项目内容包，平台不得通过硬引用依赖。
- MF输入、输出与参数使用准确英语，配备中文描述和合法范围；新资源路径需通过真实资产注册表检查才生效。

## 二、着色空间与数据

基础色彩色纹理采用适当sRGB（标准红绿蓝颜色空间）采样；Normal（法线）和ORM（环境遮蔽/粗糙度/金属度）作为数据纹理禁错误色彩空间处理；高光和粗糙度遵循PBR范围。世界位置与积雪高度单位厘米，遮罩0至1。大世界使用稳定的世界空间计算，校验原点偏移和高精度位置。

## 三、质量等级

- `High`（高画质）：在质量预算允许时增加细节法线、RVT（运行时虚拟纹理）、局部动态覆盖与高级粒子外观。
- `Medium`（中画质）：减少昂贵世界噪声与采样，保留影响识别的基础遮罩。
- `Low`（低画质）：使用Lite（轻量）母版、简化透明/反射/位移与关停非必要动态效果。

以上是功能档位，不代表具体GPU消耗已通过测量。材质静态开关带来Shader（着色器）变体数量增长，必须按实际Cook与ProfileGPU结果控制组合数；透明VFX特别关注Overdraw（过量绘制）。

## 四、验收等级

`Declared`（仅声明）→ `Authored`（引擎创建和保存）→ `ShaderValidated`（着色器编译）→ `RuntimeValidated`（客户端显示及功能）→ `CookValidated`（客户端包含/服务器剥离）→ `VisuallyApproved`（人工视觉签收）。

不得越级标记，也不得用作者脚本存在、字符串路径存在或源码单测替代UE资产回读和真实GPU验收。
