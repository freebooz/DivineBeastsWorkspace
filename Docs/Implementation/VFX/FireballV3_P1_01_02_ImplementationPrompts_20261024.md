# 《神兽联盟》火球V3 P1—01/02 纹理、材质与 Niagara 实施提示词（2026-10-24）

适用工程：DivineBeastsWorkspace／Unreal Engine 5.8。只实现01“双手初燃”与02“双掌蓄力”，保持服务器权威施法和发射时序不变，不进入03/04、飞行或爆炸，不替换正式 VFX 定义。

## 一、统一视觉约束

基于用户已批准的P0/P1概念图及最新上传的真实火焰参考图，采用《王者荣耀》式明快奇幻色彩，同时保留《神兽联盟》火元素主色 #F16B46。中心为有限面积暖白金高温光，内焰金黄，厚实主火焰橙金到朱红，外部少量琥珀色翻卷涡流和细薄暖烟。禁止大面积纯白过曝、硬边、锯齿、颗粒噪点、锐化伪细节、塑料光感与密集随机火星。光照平滑，色阶连贯，游戏固定镜头下小尺度仍清晰。

## 二、纹理制作提示词

请制作一组专供角色左右掌心使用的连续三维感火焰 Flipbook（序列帧贴图），从单朵掌火的小型初燃，演进为自然扩张和翻卷的掌心火团。首先设计并人工审核火焰参考母帧，再通过 Niagara Baker（粒子烘焙器）或 Blender/Houdini 的连续动画烘焙，生成真正连续的帧。每一帧的透明边缘采用柔和Alpha衰减，保证火舌轮廓连贯、中心位置稳定、首尾循环自然，不允许分别生成16张AI静态图后直接拼接。

计划正式输出：PNG RGBA，1024×1024，4列×4行16帧，每格256×256；单帧图像四周保持防纹理串格安全区。不得把黑色背景烘焙到Alpha里。低频火焰形态变化优先，白金内核控制面积，暖金中层厚实，橙红外焰自然上扬。图集随Texture2D导入时验证sRGB、压缩、Mip与UV串帧；独立遮罩作为线性数据处理。辅助火星以256×256或512×512柔和椭圆纹理表达，避免星芒锐化。

工程当前已有 FireMage 火焰纹理 T_PY_FlameFlipbook（1254×1254）；P1审核仍复用此源。不经独立图集审核，不替换正式纹理，不谎称已输出1024新纹理。

## 三、材质制作提示词

复用已登记的 M_PY_Flipbook（火焰母材质）、M_PY_Additive（火星叠加母材质）、MI_PY_FlipbookCore 和 MI_PY_Ember。禁止修改公共母材质。在项目 Review/V3/P1Hands/Materials 中为01、02分别建立两份独立材质实例，保留原母材质参数接口 Energy（自发光能量）和 Density（火焰密度）。

01初燃参考值：核心 Energy=1.65、Density=0.54；火星 Energy=2.7、Density=0.38。
02蓄力参考值：核心 Energy=2.40、Density=0.78；火星 Energy=4.2、Density=0.65。

这些参数是从原FireMage发光材质降低亮度后的审核初值，不代表实机视觉已通过；需在相同曝光、镜头与分辨率下对比01/02火焰是否可见，避免实际Alpha被压低到看不到火焰。若母材质参数曲线不足以实现用户火焰参考效果，只能在独立P1审核目录复制母材质并增加柔和内核、橙色中层和边缘透明衰减；禁止直接编辑平台公共母材质。

## 四、Niagara 实现提示词

以现有可运行的 NS_PY_Charge 为源，创建两个不同的项目层审核Niagara System（粒子系统）：
01：NS_DBA_Fireball_P1_01_HandsIgnite_Review。
02：NS_DBA_Fireball_P1_02_PalmsCharge_Review。

复用HandFlame（手部火焰）与GatheringSparks（汇聚火星）两个CPU发射器及其现有Flipbook动画；分别将新建的阶段材质实例应用到两发射器。左右手各实例化一次审核系统，不新建平行 VFX 框架。

使用实际骨架 hand_l、hand_r 的 World Space（世界空间）坐标确定发焰中心。审核FireMage模板内部存在 x+65cm、z+135cm 的可见火焰偏移，需要在专用审核适配中正确校正；正式上线时由英雄骨架对应的Socket或可配置偏置提供位置，不允许对十二生肖永久硬编码Manny数值。镜头先固定为三分之四视角。

01双手初燃：两侧掌心火团尺寸约16–22厘米，气流轻缓上扬，极少量火星，短周期微弱呼吸式亮度变化。审核实例初始整体缩放0.43；时长为本地表现测试段，不改变服务器时序。

02双掌蓄力：两个火团约25–35厘米，具有厚实上扬火舌和缓慢旋转的金橙环流，内核明亮但保留丰富橙色细节，火星略多但不遮挡手部动作。审核实例初始缩放0.68；动作中心仍在两掌，不提前形成03阶段的中央大火球。

优先通过独立审核资源的材质实例参数、粒子尺寸和数量调节，不复制游戏伤害、碰撞或运行时施法计时逻辑。发射器采用已有GamePlatformVFX规范的分类与伸缩预算；低画质优先降低火星和外围装饰，保留主火焰。

## 五、审核门禁

以 UE5.8 原生Editor/PIE真实运行证明：两份Niagara System与四份材质实例存在、保存后可冷加载、均正确引用审核材质；同时验证左右掌心定位正确、01明显弱于02、火焰在角色手部随动作移动、没有空白或脚底起火、平滑柔和且符合用户参考形态。引擎编译的错误数、GPU或CPU模拟结果、截图/视频和人工验收状态分别独立记录；任何一个未完成，都不得宣称正式视觉验收通过。暂不替换正式火球、修改GAS或自动提交主分支。
