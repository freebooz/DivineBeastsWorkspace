# SSLM 统一插件 HUB 界面设计

日期：2026-11-14。状态：用户已授权原生实施；按最新三列大卡片设计制作，人工验收待完成。

2026-11-14复审：独立封面已制作并导入，但艺术质量尚未全量通过；水域封面存在山岩玉石化问题，须按[艺术规范复审记录](ArtStandardsReview.md)修正。数量、导入与保存重载通过不等于人工艺术验收。

## 唯一入口

现有开发入口 → 插件 HUB → 选择插件 → 插件专属工作台 → 独立演示/调试场景 → 返回 HUB。

全部插件从同一个 HUB 进入。各插件保留独立调试环境和页面，主菜单不再展示 70 个平行入口。使用现有目录与执行器，不另建注册表、播放器或第二套开发框架。

## 界面布局

- 顶栏：SSLM 标识、插件工作台、点击卡片进入的简短提示及审核状态。开发宿主不伪装生产登录入口。
- 主体：三列大卡片，上部为用途图片，下部为中文标题及文字说明。整张卡片均可点击，图片只表达用途，不冒充实际运行截图。
- 不显示目录树、分类侧栏、搜索框、筛选工具、列表切换或右侧详情栏；不通过其他名称恢复这些控件。
- 底栏：向下滚动与用途插画提示。不分页，不显示页码或翻页按钮；右侧滚动条连续浏览全部插件。

本轮审查快照为 70 项：平台 41、MOBA 2、项目代码 5、内容包 20、第三方编辑器工具 2；48 个一方代码插件是前三项合计。上述分类仅保留在内部数据与说明中，不作为 HUB 可见目录。实际实现由现有 PluginDemoManifest/目录资产计算数量，不硬编码设计稿数字；内容包仍属于项目第三层。

## 交互与状态

1. 通过鼠标滚轮、滚动条或键盘浏览全部插件；沿用稳定目录顺序，进入并返回后卡片不会无故重排。
2. 单击卡片打开对应插件工作台，键盘 Enter 或手柄确认执行相同动作；不先打开 HUB 右侧详情，不自动运行测试、不改地图、不触发服务器操作。
3. 缺少运行依赖时由卡片状态及工作台说明展示原因；实际执行仍按真实资格禁用。登记、页面加载、场景加载、已执行及人工审核分别记录。
4. 返回 HUB 恢复原卡片焦点及可见位置。场景退出先沿用适配器 Stop/清理合同，再导航；取消不得恢复旧世界回调。
5. 卡片支持正常、悬停、按下、禁用四态，悬停以细金边和温和高光提示；键盘/手柄焦点同样可见。此版不设置收藏或最近使用菜单。

## 架构与性能约束

沿用 DivineBeastsDemoHubScreen 的统一菜单、OpenPluginPageButton、OnPluginSelectionChanged 和现有目录/ViewModel通知。GamePlatformUI 提供中立控件与主题能力；DBAClient 的 DivineBeastsDemoClient 负责项目装配；真实视觉资产归现有 DBAUIPack_Core。

首次读取快照，随后事件更新，禁止 Tick 或定时查询业务状态。采用虚拟化 TileView；每个插件独立PNG和Texture2D，原图不重染，sRGB、无损UI压缩、无mipmap，缩略图最大边512。ScaleBox按比例裁切，Image白色乘色，不通过滤镜弥补颜色链路。70份图片映射存于现有卡片默认数据，不创建第二套业务注册表、场景相机或实时预览。进入选定插件仍沿既有数据租约。GPU、内存及跨分辨率性能未实测，不宣称性能预算达标。

封面遵守《SSLM全局美术配色策略与色彩设计规范V3.0》及UITextureVisualPolicy：自然场景保留明快生态色、山水层次和暖冷关系；象征性工具采用温润碧玉、玄墨青与少量鎏金；角色保持生肖识别。禁止颗粒、砂砾、高频锐化及全图强玉绿色滤镜。封面是用途插画，不代表已有模型或实际运行效果。

新文件保持无下划线；既有 PluginId、插件挂载点和序列化身份保持稳定。原生实施后须通过 Monolith 编译、保存、冷重载和人工交互验收。
