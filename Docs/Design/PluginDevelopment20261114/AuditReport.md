# SSLM 插件演示关卡、开发 UI 与 3D 资源审查

审查日期：2026-11-14。范围：当前主工程 `Game/DivineBeastsArena.uproject`、`Game/Plugins` 下全部项目插件，以及现有演示编目和项目内容。引擎内置插件作为宿主依赖，不算成新的项目插件。当前 main 含其他任务的未提交修改，全部保留。

## 结论

**各插件已有独立 UI 页面，但尚未形成“每插件独立演示关卡、功能运行、证据、人工审核”的完整闭环。** 应复用现有开发目录、页面基类和执行器，补齐独立根关卡及缺失案例，而非重建一套插件调试系统。

## 具体缺口

1. **共享大厅过于集中。** 21 个插件的部分案例集中在 `L_DBA_PluginDemoHub`，20 个内容包集中在 `L_DBA_AssetGallery`。现有页面是按插件固定上下文的真实 Widget，不是缺 UI；需要改善的是独立场景、具体参数和审核信息。
2. **9 个插件缺已登记场景案例。** DBAArena、DBAGameplay、DBAServer、DBAWorlds、GamePlatformLocalization、GamePlatformLobby、GamePlatformVillage、GamePlatformArena、MobaPresentation。不能通过增加空地图宣称功能已实现。
3. **功能状态与源码需要重新对齐。** 索引写入 4 项 wired、198 项 registered、81 项 unregistered、5 项 blocked；但源码已存在服务、表现、世界、玩法和编辑器适配注册。不能把“仅 4 项 wired”解释成“只有 4 项功能可运行”，也不能从工厂注册推断全部可用。应逐案例核对入口、资格、依赖、结果、取消和清理。
4. **地图治理尚未闭合。** 当前 56 个开发/样例/历史地图未由这 211 个案例引用；先判定活动审核、供应商样例、历史实验或待接入，不自动删除。水体还存在两个相似位置的 `L_GP_WaterReview`，必须读引用和实际地图内容后再确定唯一活动入口。
5. **独立运行资格需明确。** BlueprintAutoLayout、GlooPrint 是编辑器工具；服务器/在线/经济类需真实依赖及权限。独立页面不意味着全部能在离线客户端执行。没有依赖时显示原因，不伪造成功。

未关联地图的 23 个插件完整列表、每插件原路径/功能数/拟建入口详见 `PluginMatrix.csv` 和 `LevelCatalog.json`。
