Use case: ui-mockup.
Create a polished, production-quality visual design image for the Chinese fantasy game SSLM (神兽联盟): one unified PLUGIN HUB, the sole menu entry point for all 70 existing plugins. This is a high fidelity UI concept for human review, not an actual engine screenshot. One complete, front-facing flat interface, widescreen 16:9, ideally 1920x1080 or larger. Fill the canvas edge to edge; no monitor, browser chrome or perspective.

VISUAL STYLE:
Refined Chinese fantasy game interface, restrained translucent dark teal and black jade panels, warm champagne-gold polished bevels, thin but tactile frames, elegant tiny leaf/flowing cloud accents confined to corners. Emerald jade primary buttons, sea-blue secondary buttons, ivory type. Smooth polished surfaces, broad continuous soft highlights, subtle low-contrast natural texture. Absolutely no grain, gritty noise, scratched metal, hard sharpened edges, fragmented highlights, giant ornaments or large empty hero scene. Quiet distant Chinese mountains and clouds only as a faint background. Highly usable desktop developer UI with restrained game character. Consistent precise spacing, crisp readable Simplified Chinese. Small decorative icons, large useful card area.
